# 连续高度地面移动整改计划

日期：2026-09-27

状态：四步核心实现和复审整改完成；整改后的组件闭环通过，Fabric 矩阵待补

## 目标

在已知地形中，让机器人连续穿过半砖、楼梯和细小高度变化，并能带速度完成已授权的一格上升、连续整格下降和直接下落多格。安全、未知、动作许可、伤害上限和输入责任继续使用现有规则。

详细接口见 [连续高度地面移动 V1](../architecture/continuous-height-ground-movement-v1.md)，验收见 [连续高度地面移动验收](../acceptance/continuous-height-ground-movement.md)。

逐文件、逐测试的执行顺序见 [连续高度地面移动实施计划](continuous-height-ground-movement-implementation-plan.md)。

## 交付顺序

### 第一步：按下一动作入口收尾

交付：

- 建立 `SegmentEntryWindow`；
- Step、JumpUp、JumpGap 和 ControlledDrop 从各自 Profile 生成入口窗口；
- Walk 根据下一动作的方向性位置和速度范围制动；
- 同帧交接继续走现有动作仲裁和输入账本。

本步不扩大任何动作入口。完成后应修复“下一整格”因圆形终点容差与方向性下降入口不一致而失败的问题。

### 第二步：连续通过小高差

交付：

- `SurfaceWalkEdge` 支持当前 Walk 可自然迈过的已知高差；
- 候选路线保留支撑面高度序列；
- 后台生成 `GroundTraversalPlan`；
- 控制器在靠近高度变化时使用完整 1.21 计算器选择输入；
- Step 保留为物理验证失败时的后备。

首版只做站立 Walk、四个正方向直线和已经授权的普通地面形状。

### 第三步：按实际用时选路

交付：

- 新地面段使用整数 tick 代价；
- 转弯计入减速和恢复速度；
- 局部物理结果按规则、入口和几何有界缓存；
- A* 与独立 Dijkstra 继续得到同一最小代价。

完成后，单块半砖不能再因为固定 Step 代价而诱导绕路。

### 第四步：带速整格升降与连续下落

交付：

- JumpUp 和下降动作增加后台求解入口；
- `SurfacePlanningRequest` 接收有类型的 `TaskDamageBudget`，默认不允许预计伤害；
- 先完成带速一格升降，再验证连续两级及以上的整格阶梯下降；
- 直接下落一格及以上时，从离边到最终落点只形成一个空中动作；
- 每个下降候选保存正式入口、执行窗口、完整空中轨迹、伤害上限和落地后的连续出口；
- 普通 Walk 可以无停顿交给已验证的升降或下降动作；
- 静止入口继续保留为后备。

本步按三个可以独立验收的子范围推进：

1. 带速一格上升和一格下降；
2. 连续两级及以上、每一级都有支撑面的整格阶梯下降；
3. 中间没有落脚面的直接多格下落。

前一个子范围通过后，后一个子范围才能复用它的入口和落地接续。直接多格下落没有任务伤害额度时只允许零伤害结果；有额度时仍要由计算器给出伤害上界并在接纳时复核。

同一目标调整伤害额度时必须生成新请求修订。后台仍可复用与额度无关的几何和物理轨迹，但必须重新执行伤害判断和路线接纳，不能让旧候选继承新的权限。

## 每一步的提交边界

每一步都要先补失败检查，再实现最小闭环，并单独通过代码审查。前一步的接口通过后，下一步才能依赖它。

- 第一步只改交接，不改变路径可达性。
- 第二步只扩大站立 Walk 的已知小高差范围，不同时加入新材质或新模式。
- 第三步只改变代价和路线选择，不改变动作安全条件。
- 第四步扩展已有升降执行链，允许连续阶梯下降和一次完整的直接多格下落；不新增任意跳跃、空中任意转向或减伤道具。

## 预计修改位置

| 文件 | 责任 |
|---|---|
| `mc2p/motion_nav/action_route.py` | 动作段入口窗口和连续地面段数据 |
| `mc2p/motion_nav/action_route_executor.py` | 前后动作交接和同帧接管 |
| `mc2p/motion_nav/fixed_route.py` | 方向性终点、变化高度跟踪和局部完整物理检查 |
| `mc2p/motion_nav/known_map_planner.py` | 小高差 Walk 边、整数 tick 代价和路线选择 |
| `mc2p/motion_nav/route_admission.py` | 连续地面段的后台物理接纳 |
| `mc2p/motion_nav/motion_solver.py` | JumpUp、连续阶梯下降和直接下落的带速求解 |
| `mc2p/motion_nav/motion_candidate.py` | 复用现有已验证动作执行链 |
| `mc2p/motion_nav/physics_1_21.py` | 只在实测发现规则缺口时修正，不复制第二套迈步规则 |
| `config/motion-navigation/` | 冻结能力范围和证据身份，不直接放宽旧 Profile |
| `tests/motion_nav/` | 交接、规划、控制、恢复和性能测试 |
| `scripts/` | Fabric 固定场景和结构化证据 |

若实现证明可以复用现有类型，就不为保持表格形式新建空文件。

## 完成条件

- 四步各自满足验收文档中的门槛；
- 高度变化路线不再默认停稳；
- 静止动作后备和既有证据继续有效；
- 未知、危险、取消、输入失联和世界变化没有退化；
- 平地、战斗追击、放置和跨隙回归通过；
- 结果、失败证据和适用范围写回四类现行文档。
