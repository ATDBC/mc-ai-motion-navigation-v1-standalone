# B08：地面速度、姿态与低通道

日期：2026-09-19
状态：已完成

## 目标

在 B07 已知支撑面和固定路线能力上，加入 Walk、Sprint、Crouch，以及已经合法进入后的 Crawl。机器人应根据正式观测确认模式，使用各自的动力学安全跟踪和停止，并在资源或输入条件失效时给出明确结果。

## 实施顺序

### 1. 正式观测

- 在客户端正式观测中加入实际冲刺和实际潜行状态。
- 将姿态、实际模式、饥饿值和饱和度投影到 `BodyState`。
- 保持 Fabric 与测试夹具使用同一协议；请求输入不能充当实际状态。

### 2. 模式配置和动力学

- 新建明确的地面模式配置，分别绑定模式、输入、姿态、准入条件和动力学 Profile。
- Walk 沿用 B06 已校准参数。
- Sprint、Crouch、Crawl 使用独立 Fabric 数据校准；不能从 Walk 参数直接按比例推导。

### 3. 固定路线执行

- 固定路线控制器接受一个明确模式，并复用原有路线跟踪、扫掠、支撑、制动、取消和输入失联逻辑。
- 模式请求发出后，以后续观测确认。切换超时、资源不足、姿态不合法分别返回不同原因。
- 当前身体碰撞箱用于安全预测；退出低姿态前检查目标姿态净空。

### 4. 动作路线和已知图

- 动作段传递 `MovementTransition.mode`，执行器选择对应模式配置。
- 规划成本使用相应模式的实测速度和资源变化。
- 保留同站位互不支配的资源标签，并加入 Sprint 快前缀失败、Walk 慢前缀成功的反例。

### 5. 验收

- 组件测试覆盖模式确认、准入、切换上限、低净空、制动、取消、输入失联和世界方向保持。
- Fabric 实测 Walk↔Sprint、Walk↔Crouch、Crawl 保持／移动／退出。
- 每类实测保存身体轨迹、请求输入、实际模式、控制时间和终态。

## 本阶段不做

- 从站立主动进入 Crawl；
- 让机器人主动通过水、活板门或世界修改制造 Crawl 入口；验收夹具可以建立低通道和预置姿态，但不计作能力；
- 跳跃、跨坑、受控下降、攀爬和游泳；
- 未知区域探索和动态实体避让；
- 完整饥饿消耗预测。

## 完成条件

- 四种模式的状态来源、输入和动力学边界明确。
- 模式切换只能由后续正式观测确认。
- 固定路线场景满足对应姿态、净空、取消和输入失联要求。
- Sprint 资源反例通过。
- Fabric 证据达到 [B08 验收文档](../acceptance/B08-ground-modes-low-clearance.md) 中的门槛。

以上条件均已满足。实测证据、指标和仍未覆盖的入口能力见验收文档。
