开始：2026-10-07；验收：2026-10-08。状态：F2-R 按冻结范围通过。

## 1. 目标

修复 F2 在建筑外角、对角柱和杂乱地形中原地拒绝目标的回归。建立能够继续发现终点几何问题的 v8 产品量尺。把潜行区间的实际交付范围写准确。

本阶段不实现路线优化器，不新增动作，不修改 Session、ExecutionSupervisor 或 Runtime 生命周期。

## 2. 批次顺序

### F2-R0：冻结失败和 v8 输入

1. 保存当前版本在建筑外角、单根对角柱、柱间目标上的失败。
2. 每个几何族覆盖四方向、正常和首条晚一 tick。
3. 分别使用产品、近战和跟随的真实目标尺寸。
4. 增加固定种子的 10%／20% 柱状杂乱地形扫描。
5. v8 保留 v7 全部任务，并新增外角、柱子、多格目标区域和斜向接近层；每层单独报告结果。

完成条件：代码尚未修改；失败可以稳定复现；输入、种子、分层和结果分类已经固定。

### F2-R1：选择最大的精确完成矩形

1. 先写失败测试，证明 L 形区域当前返回 `UNSUPPORTED`。
2. 从障碍裁剪后的精确矩形块中选择面积最大的一块。
3. 面积相同时按 `min_x`、`min_z`、`max_x`、`max_z` 固定顺序选择。
4. 沿用既有顶点支撑检查、净空查询、依赖收集和 `STANDABLE_REGION` 重放。
5. 障碍、支撑或目标变化使选择结果改变时，现有路线必须失效。

完成条件：新增正例完成；返回矩形始终位于原目标和真实可站区域内；原 528 项没有退步。

### F2-R2：Windows 与 v8

5. 报告动作分支量尺。当前起点是直接动作分支 42、控制器代理 0、求解策略代理 1、能力判断 2、未分类 0。

### F2-R3：Fabric 对照

## 3. 止损规则

- 需要按外角、方向、目标类型写生产分支时停止；
- 需要把完成区域扩成外接矩形时停止；
- 需要降低身体宽度、支撑比例、未知或危险门槛时停止；
- 需要修改 Session／Runtime 生命周期时停止；
- v8 只能靠删难例或改变分组通过时停止；
- Fabric 未完成前不能宣布 F2-R 关闭。
