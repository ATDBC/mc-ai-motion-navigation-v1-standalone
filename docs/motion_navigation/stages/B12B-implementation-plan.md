# B12-B 实施计划：部分观察与战斗移动

日期：2026-09-26
状态：已完成

## 1. 范围

本轮实现 [B12-B 部分观察与战斗移动 V1](../architecture/B12B-partial-observation-combat-motion-v1.md)，不增加多目标策略、远程武器、新运动原语或战斗专用寻路器。

## 2. 实施顺序

1. 先用失败测试固定普通地面视角兼容、超限拒绝和非地面拒绝；
2. 修改仲裁兼容判断，让普通地面已验证移动可在稳定战斗视角下继续；
3. 增加移动近战组合测试，实际覆盖前进、左右横移和后退；
4. 固定交战目标遮挡、补看、观察缺口和权限撤销的测试；
5. 运行运动导航与 C1、B11、B12-A 回归；
6. 增加固定 Fabric 清单并实测；
7. 重跑 B10 跨隙，确认权限没有扩展到空中动作；
8. 把结果写入 B12-B 验收记录并更新阶段状态。

## 3. 代码边界

- `ActionIntentV1` 保存移动生产者声明的同帧水平转角上限；
- `NavigationSession` 只为普通 `WalkSegment` 声明上限，并把这类意图限制为一帧；
- `ActionArbiterV1` 根据移动所依据的观察序号和最终视角核对上限；
- `MovingMeleeDriver` 继续组合导航提案、目标视角和攻击，不接管路线安全判断；
- 交战记忆继续拥有隐藏位置的使用许可。

## 4. 结束条件

以 [B12-B 验收计划](../acceptance/B12B-partial-observation-combat-motion.md) 为准。代码完成、组件检查通过与实机通过分别记录，不能相互替代。
