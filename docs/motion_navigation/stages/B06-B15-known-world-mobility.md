# B06–B15：已知地形多能力移动

日期：2026-09-19
当前状态：B06、B07、B08、B09、B09-R 已完成，B10 尚未开始

## 阶段目标

在已知地形、已声明的身体条件和风险约束下，机器人能够选择合适的移动方式，连续、可靠地到达可达目标。

本批只实现玩家自身运动。不使用载具或消耗型道具，不主动改变世界。未知探索、观察站位、动态实体避让和跟随不属于本批范围。

详细交付顺序见 [B06–B15 计划](../architecture/mc_navigation_B06_B15_plan_java_1_21_0.md)。改变阶段顺序或验收门槛时，先更新 `decisions`。

## B06：版本、共享契约和普通材质

状态：已完成

### 已交付

- 固定 Minecraft 1.21、Fabric Loader 0.15.11、Fabric API 0.100.6+1.21、Yarn 1.21+build.9、Java 21、Python 3.11、50 ms tick 和关闭自动跳。
- 固定正式观察／动作协议、客户端 mod、独立原版服务端角色、基线源码提交和三类证据权限。
- 从固定客户端 JAR 导出 1,062 个原版方块注册名，并保存源 JAR 哈希。
- 建立方块运动分类。只有明确登记且几何相符的完整方块可以使用普通地面模型；特殊机制和未分类方块不能自动退化成普通方块。
- 新建 B06 普通步行和一格上升 Profile。旧 B03/B05 Profile 保持不变。
- 新建 `GoalState`、`MovementTransition`、资源变化和资源状态契约。
- Walk 和 JumpUp 的规划边、候选路线、路线接纳和动作段传递同一份动作转换。
- 搜索保留同一站位上互不支配的资源标签。较快但资源不足的前缀不会覆盖较慢但可到达的前缀。
- Fabric 实测泥土、玻璃、草方块、橡木板和石头。五种材质均用同一套参数完成固定路线步行和一格上升。

### B06 不包含

- 半砖、楼梯、地毯、积雪层等非完整支撑面；
- Walk 以外的地面姿态与速度模式；
- 跨隙、下降、攀爬、游泳和特殊接触机制；
- 未知区域探索和动态障碍处理。

详见 [B06 验收记录](../acceptance/B06-version-contracts-ordinary-materials.md)。

## 进入 B08 的条件

B07 已满足进入条件，并继续使用 B06 的环境身份、方块分类、目标状态和动作转换契约。非完整形状由世界几何、支撑面与能力查询处理，没有在规划器中按方块名增加捷径。

B07 的完成范围和证据见 [B07 阶段记录](B07-support-surfaces-shapes-steps.md)及对应验收文档。B08 开始前应单独冻结地面速度、姿态与低通道的范围和验收门槛。

B08 的范围和验收门槛已经冻结，见 [B08 阶段记录](B08-ground-modes-low-clearance.md)、[地面移动模式架构](../architecture/ground-modes-v1.md)和[验收文档](../acceptance/B08-ground-modes-low-clearance.md)。

## 进入 B09 的条件

B08 已完成四种地面模式的正式状态、独立动力学、固定路线执行、取消、输入失联和低通道退出。Crawl 的主动入口没有提前实现。B09 可以在这些共享契约上增加参数化上升、跨隙和受控下降，不另建地面模式或输入出口。

## 进入 B10 的条件

B09 已完成跨隙和受控下降的入口、轨迹、落地、规划边、后台选路、路线接纳和实机执行。B05 的一格上升继续沿用原控制器。三类空中动作都有明确的稳定入口与低速出口，取消和输入失联不会在空中假装停止。

B09-R 又固定了给定输入的逐 tick 计算、状态构造、碰撞、姿态、多步演算、差分和性能边界。它保持只读，没有接管旧控制器。B10 可以只处理动作之间的带速接续和短时执行走廊，不得重新复制空中物理、目标、地图或输入出口。

B09 完成范围和证据见 [B09 阶段记录](B09-parameterized-air-transitions.md)、[空中转换架构](../architecture/air-transitions-v1.md)和[验收记录](../acceptance/B09-parameterized-air-transitions.md)。B09-R 见 [阶段记录](B09R-physics-calculator.md)、[运动计算器架构](../architecture/physics-calculator-1_21-v1.md)和[验收记录](../acceptance/B09R-physics-calculator.md)。
