# C1-B：移动目标连续近战

日期：2026-09-24
状态：已完成

## 目标

在已知平地中追击一只正常移动的普通成年僵尸，按攻击冷却重复接近、瞄准和攻击，直到正式观察明确确认同一目标死亡。

这一阶段同时验证按需目标位置、交战记忆、移动导航目标、连续攻击、准确生命记录、死亡确认和固定生物随机种子。

## 包含范围

- 单个普通成年僵尸；
- 僵尸保留正常 AI，并仇恨和追逐机器人；
- 测试夹具消除僵尸对机器人的伤害和击退影响；
- 世界、场景、决策和僵尸 AI 随机种子全部冻结；
- 目标必须先被直接看见；
- 首次确认机器人命中后允许建立 C1-B 交战记忆；
- 只按需查询已登记目标的位置、速度、生命和死亡状态；
- 目标显著移动后更新攻击站位，小幅移动继续使用仍有效的路线；
- 每次攻击仍使用 C1-A 的客户端目标核验和命中确认；
- 保存完整观察流和各层因果记录。

## 不包含范围

- 机器人受伤、击退后的动作责任和路线恢复；
- 多敌人选择与威胁排序；
- 根据目标生命决定进攻或撤退；
- 伤害预测、暴击、附魔、药水和装备切换；
- 羊、牛或玩家的正式跟随能力；
- 友方玩家仇恨关系；
- 遮挡搜索、未知区域探索、远程武器和主动改变世界。

## 完成结果

- 按需实体查询已能读取一个已登记目标的位置、速度、姿态、生命和死亡事实；
- 交战记忆只在确认命中后允许使用隐藏目标位置，并在过期、取消、卸载、死亡、修订或世界变化时撤销；
- 移动目标站位只在超过阈值、跨支撑区域、旧终点失效或路线不可接续时修订；
- C1-A 与 C1-B 共用单次近战核心；C1-B 负责重新接近、重复命中和死亡终态；
- 独立服务端夹具在第一次 AI tick 前应用僵尸随机种子，并保存实际回执；
- 当前源码的正式 Fabric 批次 `20260924T091651661550Z-34995f43` 通过 20／20 个正例和 10／10 个反例，逐帧重放 3,145 次决策；
- 整段控制计算 P95 为 5.7939 ms，P99 为 7.1828 ms；本轮 282 项 B10—C1-C 相关回归和 345 项运动／导航专项检查通过；
- C1-A 回归批次 `20260924T014825771857Z-fc02a0b0` 再次通过 40／40 个正例和 7／7 个反例。

## 实施顺序

1. 扩展按需实体查询，提供单个已登记目标的位置、生命和死亡事实。
2. 建立交战记忆及其进入、持续、过期和撤销检查。
3. 增加移动目标站位更新，并复用现有导航路线与接纳链。
4. 从 C1-A 中抽出共享的单次近战控制核心，保持 C1-A 入口行为不变。
5. 建立 C1-B 连续任务执行器，处理重新接近、冷却、重复命中和死亡终态。
6. 增加服务端测试夹具的僵尸 AI 种子设置和应用证据。
7. 完成组件、Java、离线重放和正式 Fabric 正反例验收。

每一步先写失败检查，再实施最小代码。不能用固定坐标、测试标签或服务端命令替代正式目标事实。

## 完成条件

- [C1-B 验收计划](../acceptance/C1B-moving-target-melee.md)中的正式正例和反例全部达到门槛；
- C1-A 正式入口和回归保持不变；
- 目标小幅移动不会引发逐 tick 全局重算；
- `VISION` 和 `ENGAGEMENT` 来源在日志中可区分；
- 目标消失不会被误判为死亡；
- 生命值不会替代命中或死亡证据；
- AI 随机种子未应用时，正式场景拒绝开始；
- C1-C 不会因本阶段实现而被提前宣称完成。

以上条件均已达到。C1-B 的伤害隔离结论仍不能替代 C1-C 的真实受击恢复证据；C1-C 已在独立阶段完成该项验收。
