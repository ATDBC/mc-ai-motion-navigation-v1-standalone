# F2：非中心地面路线执行与终点接近

日期：2026-10-07。状态：冻结范围实现与正式验收完成。

## 1. 阶段目标

先让普通地面控制器可靠执行任意浮点坐标折线，再把贴墙、墙角、走廊尽头和平台边缘终点接入同一能力。

中心点搜索保持不变。本阶段不实现路线优化器、疾跑路线、动态避障或新动作类型。

## 2. 实施前的起点

- `FixedRoute` 和 `_RouteGeometry` 已支持任意浮点坐标与连续折线投影；
- 普通开阔路线走快速地面预测；
- 碰撞候选目前在 `sweep()` 返回阻塞时直接失败；
- `StateAnchor.physics_state` 已由正式执行链传给 `FixedRouteController`；
- 1.21 计算器已有碰撞裁剪和 `sneak_edge_clipped`；
- 当前玩家常站位置历史约为 `114/400`，精确当前值需在 F2-0 重新冻结。

## 3. 交付顺序

### F2-0：冻结量尺和非中心执行基线

1. 手工提供偏移直线、斜线、沿墙切线、中心转非中心、小高差非中心线和中途正面墙路线。
2. 记录当前完成、失败原因、路线进度、横向误差、候选数量和控制耗时。
3. 重新冻结玩家常站位置清单，并保留种子 187、连续高度和严格下降对照。
4. 建立错误副本，证明量尺能发现：中途撞墙被接受、危险墙接触、走廊越界、未声明区间潜行、潜行不释放、完整复核超过三个候选。

完成条件：每个失败已经归入路线跟踪、墙面结果、边缘输入、完成区域或真正不可达；生产代码尚未修改。

### F2-1：通用完整复核

1. 在 `safe_ground_control.py` 增加普通路线候选复核，输入正式物理状态、路线几何和当前帧查询缓存。
2. 推演完整输入租约与停止尾迹，返回每 tick 状态、最小支撑、缺失格、依赖和路线进展。
3. `FixedRouteController` 只在快速候选因已知水平碰撞或支撑边界失败时，按稳定顺序复核最多三个候选。
4. 沿墙仍取得进展的候选允许执行；中途正面墙、危险、未知、越界和失去支撑继续拒绝。

完成条件：偏移、斜线、沿墙和中心转非中心路线通过；中途正面墙及负例保持失败；开阔路线逐帧不变；专项 P95 达标。

### F2-2：路线能力区间与潜行防坠

1. 新增 `GroundRouteExecutionContract` 和 typed 能力区间。
2. 首版只实现 `SNEAK_EDGE_GUARD`。
3. 普通候选失去支撑且当前进度在能力区间内时，才复核潜行候选。
4. 离开区间或终点停稳后释放潜行，等待正式姿态确认。

完成条件：声明过的非中心边缘路线完成；相同路线未声明能力时安全拒绝；取消、修订、失联、外力和支撑移除有界结束。

### F2-3：终点区域首个用例

1. 计算原目标、支撑和净空的精确 `GroundCompletionRegion`。
2. 最终 Walk 使用入射投影和边界余量选参考点，不再经过格心折返。
3. 贴墙终点复用 F2-1，平台边缘终点只为末段声明 F2-2 能力。
4. 完成仍由原 `GoalState` 和正式身体观察确认。

完成条件：冻结的物理可达墙面与边缘正例全部完成；危险接触、掉落、伤害和终态潜行均为零。

### F2-4：正式组合验收

1. 运行 Windows 完整正序、逆序。
2. 重跑产品、协调、故障、跟随和世界变化五组。
3. 重跑非中心路线和玩家常站位置清单。
4. 在 Fabric 对照非中心中途路线、墙面终点和边缘终点。
5. 保存性能、命令、来源提交、哈希和失败边界。

## 4. 止损规则

出现以下任一情况就停止当前批次：

- 按墙角、方向或场景名称增加分支；
- 为安全接触增加新的动作类型；
- 修改 Session、ExecutionSupervisor 或 Runtime 生命周期；
- 开阔地进入完整物理慢路径；
- 使用墙钟改变候选或路线；
- 两轮优化后控制帧仍未达到门槛；
- 缩短停止尾迹或降低未知、危险、支撑和严格动作门槛；
- 路线区间能力无法由未来路线优化器直接生成。

F2-1 未通过时不实施潜行或终点用例。F2-2 未通过时可以保留已验收的通用墙面结果判断，但不能声明边缘路线支持。

## 5. 2026-10-07 实施与当前结果

Task 1 冻结 528 项输入和错误副本；Task 2 补已知墙面与支撑边界的有界完整复核；Task 3 增加 typed 能力区间和潜行释放；Task 4 让最终普通 Walk 使用原目标内的完成区域，并独立复核区域依赖。Task 5 新建正式 Fabric 入口，复用原 Runtime、NavigationSession 和观察链。

Task 5 实机首条晚到暴露多点路线没有启动余量。修正只补首次静止入口的中性前缀证明，沿用原启动窗口，命令仍是一 tick。没有修改 Session、监督者或 Runtime 生命周期。

正式 Windows 正逆各 `1627/1627`，场景哈希不变。故障 `16/16`、世界变化 `19/19`、跟随 `10/10`、协调 `1448/1448`。产品 `1998/2000`，比冻结 `1718/2000` 新增 280 项，旧成功退步 0，异常和安全违规为 0。
