# B10-B：单动作命令求解与独立验证

日期：2026-09-21
状态：等待 B10-A 完成

## 目标

在 B10-A 的同高一格跨隙范围内，自动搜索真实命令和时序，形成可追溯的动作证明，并通过固定测试入口完成独立 Fabric 实机验证。

B10-B 仍不允许普通规划任务自动选择新求解器。它证明“可以自动求出并真实做出来”，B10-C 才证明“可以由规划器接纳并连续执行”。

## 交付

### 快速可达性筛选

从已知支撑、净空、入口速度、方向、身体和资源条件生成有限候选。明确硬冲突、缺信息、未支持、待求解和预算耗尽。

### 命令求解

在真实输入链允许的有限参数上搜索，例如跳跃开始、前进／冲刺释放时机和已经授权的朝向。每个 tick 都用预测状态重新投影输入，再调用同一个 B09-R 计算器。

不得直接优化无法由正式输入产生的连续 `TickInput`。

### 独立轨迹验证

检查完整轨迹、途中碰撞、离地、落点、终端速度、恢复范围、资源条件和任务出口。计算成功但落错位置、撞墙或无法恢复的候选仍然失败。

### 已验证动作结果

命令、投影输入、预测轨迹、入口—出口关系、世界依赖、规则身份、资源完整性和执行窗口形成同一份不可变记录。

## 试验范围

- 先在 `+Z` 方向开发和定位问题；
- 正式单动作能力验收覆盖四个正方向；
- 仍使用草方块、同高一格空隙、低速入口和 B09 风险策略；
- 校准组和独立验证组分开；
- 通过后仍不授权对角、多格跨越、复杂形状、途中转向或极限入口。

## 必须保留的失败

- 高度和距离分别在限值内，但联合条件无解；
- 端点可站，途中净空不足；
- 能落地，但没有必要恢复范围；
- 需要先加速，当前入口不能直接起跳；
- 搜索预算用尽；
- 世界或状态锚点在求解期间变化；
- 固定输入 Profile 可过，但新求解器没有在预算内找到；
- 求解器找到模拟输入，但正式命令投影无法产生。

## 完成条件

- 自动产生的命令不依赖后验真实轨迹；
- 四个正方向的独立 Fabric 样本达到冻结门槛；
- 负例给出正确分类，不伪装地形绝对无路；
- 入口和出口保持关联，没有用宽范围笛卡尔积放大能力；
- 求解和验证运行在后台或有界离线入口，不阻塞控制线程；
- B09 旧 Profile 继续保留作回归，不在求解失败时静默替代新结果。
