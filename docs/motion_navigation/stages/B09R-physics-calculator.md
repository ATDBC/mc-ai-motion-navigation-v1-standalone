# B09-R：Minecraft 1.21 玩家运动计算器

日期：2026-09-20
状态：已完成首版实现与支持域验收

## 目标

在 B10 连续接续之前，建立一个无副作用的逐 tick 计算器。它用真实身体状态、已生效输入和已知几何计算运动结果，为后续短时轨迹比较、动作衔接和安全检查提供同一套物理规则。

## 已交付

- 增加 opt-in Fabric tick 诊断，以同一个 `movement_tick_id` 记录运动前状态、采样后输入、运动 yaw 和运动后状态。
- 建立完整状态、输入、规则身份、结果和失败分类。缺字段与来源冲突不能进入计算器。
- 实现普通地面、普通空中、起跳、冲刺资格与释放、重力、阻力、分轴碰撞、接触事件、潜行防跌落、普通跨步和已支持碰撞盒形状。
- 实现 Walk、Sprint、Crouch 和合法 Crawl 保持／退出。主动进入 Crawl 仍不属于本阶段。
- 把已知跳跃消耗与尚缺服务端时钟的资源结果分开表达。
- 实现固定输入序列 rollout、保存恢复、独立分支、摘要、预算、取消和外部事件边界；汇总结果保留关键事件与资源完整性。
- 提供 Fabric 单步／开环差分工具和固定性能基准。
- 提供只读逐 tick 回放页，把 Fabric 实机轨迹、计算轨迹、输入、事件和放大误差放在同一条时间轴上查看。
- 保留 B09 及更早控制器。新计算器没有接管在线输入。

## 未包含

- 输入搜索、最佳起跳点、最佳松键点和可达性求解；
- B10 的连续动作接续、执行走廊和在线滚动修正；
- 特殊地面、水、攀爬、飞行、鞘翅和完整资源时钟；
- 将计算结果直接转换为动作许可。

## 进入 B10-A 的条件

- 支持域内单步与开环差分没有离散状态错误，误差低于已冻结阈值；
- 缺状态、未知几何、未支持规则、预算和外部事件有不同结果；
- 保存恢复和分支没有状态串扰；
- 性能基线和当前可承受的候选规模已经记录；
- 旧在线行为没有被计算器改写。

基础运动的既有实机差分满足上述门槛。审查后新增的潜行防跌落、落地同 tick 跨步、冲刺单独释放和连续姿态切换仍需专项 Fabric sidecar；在补齐前，只能把它们记为组件已通过。B10-A 只前置首个试点实际使用的规则分支，其他分支在对应能力启用前补齐。详细边界见 [B09-R 验收记录](../acceptance/B09R-physics-calculator.md)和 [B10-A 阶段记录](B10A-online-motion-foundation.md)。
