# B07：支撑面、非完整形状与小台阶

日期：2026-09-19
状态：已完成

## 阶段目标

在已知地形中，机器人能从真实碰撞形状生成正确站位，并通过已经校准的小台阶动作穿过代表性的非完整方块组合。未知、未支持形状和特殊接触机制仍会明确拒绝。

本阶段沿用 B06 的环境身份、方块分类、目标状态、动作转换和资源契约。详细边界见 [支撑面与小台阶 V1](../architecture/support-surfaces-v1.md)。

## 交付范围

### B07.1 跨格碰撞与依赖

- 允许 `BlockGeometry` 的碰撞体在 Y 方向向上越出所属格，同时保留水平本格限制。
- 让扫掠和支撑查询读取下方一格中可能伸入目标区域的几何所有者。
- 依赖保存所有者格，而不是碰撞发生处的格。
- 覆盖负坐标、区块边界、状态变化和未知邻格。

### B07.2 支撑面与表面节点

- 新增 `support_surfaces.py`，从已知碰撞盒提取顶面、合并覆盖并生成安全站位。
- 新增有类型的 `SurfaceNodeId`，保留真实脚底高度和表面依赖。
- 同一 X/Z 的不同高度不能合并；窄到无法容纳角色脚印的表面不能生成节点。
- 普通完整方块仍能生成与 B06 等价的站位和路线。

### B07.3 小台阶闭环

- 增加 `StepUp` 和 `StepDown` Profile、查询、规划边和执行控制器。
- 用 Fabric 校准普通步行下可自动迈上的高度、入口速度、落点范围和停止边界。
- 路线接纳重新核对动作入口、依赖和当前身体状态。
- 动作路线执行器按顺序交接 Walk、Step 和 JumpUp，不合并不同动作。

### B07.4 代表形状

正式支持范围以配置和实测为准，至少包含以下代表：

- 下半砖和上半砖；
- 直楼梯和一个转角楼梯；
- 地毯；
- 至少三种积雪层数，包含可自动迈步和超出当前范围的边界；
- 土径；
- 栅栏、墙、薄障碍和开／关活板门的正确阻挡或放行。

耕地只验证几何，动作仍因 `world_change_risk` 拒绝。含水或带特殊接触效果的组合不在 B07 获得通行能力。

## 实施顺序

1. 先写跨格碰撞反例，确认当前实现遗漏或拒绝这些形状。
2. 修改世界几何和统一查询，保持 B02–B06 回归通过。
3. 写表面节点反例，再实现表面提取与稳定身份。
4. 让已知图在表面节点上生成同高 Walk 候选，并与独立 Dijkstra 比较。
5. 在 Fabric 中校准最小 StepUp／StepDown，再冻结 Profile。
6. 接入规划、路线接纳和动作执行，补取消、输入失联和世界会话测试。
7. 跑代表形状矩阵、原平地、墙、坑和 JumpUp 回归。

每一步先增加修改前会失败的行为测试。B07.1 和 B07.2 只建立真实几何与站位，不提前宣称实际可通过；实际通行必须等 B07.3 的闭环证据。

## 进入 B08 的条件

- 所有强制形状场景完成或返回正确的拒绝类型。
- 代表性上／下小台阶在 Fabric 中由真实输入完成，不使用传送冒充动作。
- 路线中的几何依赖覆盖跨格碰撞所有者；相关状态变化会撤销旧路线。
- 未知不能被当作空气，未验证材质和几何不能自动普通化。
- B02–B06 专项回归全部通过。
- 实际结果、失败证据和性能数据写入 B07 验收文档。

## 完成结果

B07 已达到上述条件。最终实现包含：

- 查询下方所有者格，处理最高伸入上方一格的碰撞盒；
- 从真实碰撞顶面生成非整数高度的表面节点，并去掉被更高碰撞体覆盖的内部顶面；
- 在独立 `SurfaceGraph` 中连接 Walk、Step 和既有 JumpUp，不改变 B04–B06 的整数节点回归入口；
- 在后台进程中从脱离实时世界的快照建表面图并搜索；
- 路线接纳与执行保留有类型的 Walk、Step、JumpUp 动作；
- 用 Fabric 实际碰撞形状完成 16 次升降、2 次同高步行和 5 类障碍阻挡验证。

Step Profile 只授权静止、低速入口和不超过 0.5 格的升降。带速接续仍留给 B10。详细数据、命令和失败修正见 [B07 验收记录](../acceptance/B07-support-surfaces-shapes-steps.md)。
