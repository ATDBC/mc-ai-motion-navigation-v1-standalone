2026-09-26 核查发现，当时的 Fabric 实机使用了已经弃用的 profile 3 稀疏射线。三态知识、按需空气、几何与地面预测结果继续有效。正式入口现已固定为 profile 4，基础观察与 B03 回归通过；B10 的动作时序仍在整改。修正计划见 [表面深度主线修正计划](B12-surface-depth-correction-plan.md)。

## 当前范围

B02 要统一时间单位、世界会话、三维支撑、未知与已知空空间、扫掠查询和普通地面预测。本阶段不接入自动寻路。

正式新主线采用可见方块事实加按需空气正例确认。早期全视锥运行原型只用于诊断，不作为正式知识输入。

## 阶段边界

B02 没有实现自动路线、检查点、探索、跳跃和软安全缓冲。墙边与坑边的缓冲、不同视角下的固定路线跟踪、停止、取消和输入失联属于 B03。

根据 D005，B02 的实机门槛采用独立 Fabric。CraftGround 保留共同契约和适配器测试，不在本阶段启动真实游戏验收。

## 进入 B03 的条件

以下条件已经满足：

1. 三态知识不会把未知当作空气。
2. 新世界会话不能复用旧会话事实。
3. 支撑与扫掠使用同一套三维碰撞几何。
4. 普通地面模型有独立实机验证误差。
5. Fabric 空气查询有明确数量上限和游戏线程耗时证据。
6. B01 四个代表场景的 B02 几何结论通过。

B03 可以开始，但必须只做固定路线步行，不得同时接入 A*、探索或跳跃。
