# B09：参数化跳跃与受控下降

日期：2026-09-19

状态：已完成

## 目标

在已知普通地形中加入跨隙和零伤害受控下降，并把 B05 的一格上升、跨隙和下降统一接入能力查询、后台选路、路线接纳和实际执行。

## 实施顺序

1. 建立跨隙与下降的 Fabric 校准场景，保留成功和边界失败轨迹。
2. 新增公共空中轨迹查询与观察驱动控制器；B05 `JumpUp` 保持现状。
3. 新增 `JumpGap` 和 `ControlledDrop` 类型、Profile 与动作边。
4. 扩展支撑面图、A*、Dijkstra 对照、后台进程和路线接纳。
5. 扩展动作路线执行器，覆盖正常完成、取消、输入失联和错误落地。
6. 运行组件回归和 Fabric 实测，记录真实性能与边界。

## 本阶段不做

- 多动作带速连续接续和无停顿跑酷；
- 预计会受伤的下降；
- 特殊地面、液体、梯子、藤蔓、滑翔和世界修改；
- 未知区域探索和动态实体避让。

## 完成条件

- 三类空中动作都有明确入口、轨迹、落地和失败边界。
- 后台可以在已知图中选择跨隙或下降，并生成有类型的动作路线。
- 轨迹碰撞、未知关键格、错误落地、取消和输入失联不会被误报为成功。
- A* 与独立 Dijkstra 对照一致。
- Fabric 场景达到对应验收文档的门槛，B02 至 B08 回归继续通过。

## 已交付

- 保留 B05 `JumpUp`，新增共享空中轨迹核心、`JumpGap` 和 `ControlledDrop` 两种独立动作。
- Profile 固定环境、材质、入口速度、方向性位置范围、实测轨迹、离地和落地边界。
- 几何查询检查方向性入口边界、整段身体扫掠、落地支撑和恢复空间。
- 控制器按正式观察推进离地、空中、落地和停稳状态；取消或输入失联后继续完成安全落地。
- 支撑面图、A*、Dijkstra 对照、后台进程、路线接纳和动作路线执行器均已接入两类新动作。
- Fabric 已完成四向重复、两条混合路线和空中中断验收，前序代表场景没有退化。

## 下一阶段

B10 可以在现有入口和出口状态上增加带速接续与执行走廊。B09 的稳定入口继续保留，不能为了减少停顿而扩大到未经校准的速度或位置范围。
