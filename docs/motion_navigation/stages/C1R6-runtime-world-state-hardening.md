# C1-R6：运行时失败处置与世界知识收尾

日期：2026-09-25
状态：已完成组件与 Runtime 集成验收；未新增 Fabric 场景

## 1. 阶段目标

C1-R6 在进入 B11 前补齐两条公共链路：

1. Runtime 不再只记录失败分类，而要执行对应的生命周期动作；
2. Runtime 每次取得正式 V3 观察后，立即更新唯一的导航世界知识，不再等某个导航会话来消费观察。

本阶段不增加放置、搭桥、部分观察战斗或新的移动方式。

## 2. 失败处置

`FailureDispositionPolicy` 继续负责分类和同原因重试计数。`PlayerRuntimeV1` 负责执行结果：

| 结果 | Runtime 行为 |
|---|---|
| `CONTINUE_WITH_INCOMPLETE_EVIDENCE` | 保持当前控制和连接；把本次运行标为证据不完整 |
| `RETRY_TASK_BOUNDED` | 清除旧任务输入来源，下一控制帧先发送中性输入；Runtime 保持可用 |
| `CANCEL_TASK` | 清除旧任务输入来源，下一控制帧先发送中性输入；上层结束或替换任务，Runtime 不因此断开 |
| `RECREATE_RUNTIME` | 清除输入、关闭后端并进入 `FAILED` |
| `END_EPISODE` | 清除输入、关闭后端并进入 `ENDED` |

任务重试和任务取消不会在失败处理函数里私自推进游戏。它们只撤销旧输入权限，并要求下一次正式控制帧发送中性输入。这样仍由 Runtime 保持唯一逐帧推进权。

已经向后端提交、但无法确认执行结果的错误仍归为 `RECREATE_RUNTIME`。C1-R6 不用继续运行来掩盖不确定输入。

## 3. 世界知识更新

Runtime 已经拥有唯一的 `NavigationObservationAdapter`。本阶段把它接到正式观察入口：

- V3 reset 成功后立即写入第一帧；
- 每次 step 完成回执核对和输入账本更新后，立即写入新观察；
- V2 运行不创建导航世界事实；
- 导航技能读取 Runtime 已经更新的适配器，并把同一帧交给自己的路线状态机；
- 正式 `RuntimeNavigationDriver` 启动时，把导航会话绑定到 Runtime 的适配器。会话不能在正式控制链中保留第二份地图。

离线规划和不经过 Runtime 的组件测试仍可显式创建独立适配器。这不改变正式运行只有一个世界知识拥有者的规则。

## 4. 实施顺序

1. 先写失败检查，证明现状只记录决定但没有执行任务级处置；
2. 让 Runtime 执行五类处置，并验证中性释放和重试上限；
3. 先写世界知识检查，证明 reset 和普通 step 目前不会主动更新适配器；
4. 在 Runtime 的正式观察入口更新世界知识；
5. 让正式导航驱动绑定 Runtime 适配器，验证切换导航任务不会丢失已知地形；
6. 运行运动导航、Runtime、C1 和公开仓库相关回归；
7. 更新架构、验收结果和项目入口。

## 5. 完成条件

- 五种失败处置都有直接行为检查；
- 任务重试和取消不会关闭客户端，也不会重放旧输入；
- 不确定后端状态仍会封存 Runtime；
- V3 reset 和每个成功 step 都在返回调用方前更新同一个世界知识拥有者；
- 两个先后创建的正式导航会话读取同一份历史地形；
- 现有 C1、B10 和运动导航回归不退化；
- 没有增加第二个逐帧推进者、第二份正式地图或新的通用框架。

## 6. 实施结果

- `PlayerRuntimeV1.apply_failure()` 执行五类有类型处置；任务重试和任务取消清除旧输入权限，并让下一帧先释放为中性输入；
- 同原因任务期限失败前两次返回重试，第三次返回任务取消；Runtime 保持可用于后续任务；
- 后端输入不确定继续关闭 Runtime，不可恢复的世界结束进入 `ENDED`；同步正式 trace 失败不会被当成异步证据降级；
- Runtime 在 V3 reset 和每个成功 step 中更新同一个 `NavigationObservationAdapter`；
- `RuntimeNavigationDriver` 在会话使用前绑定 Runtime 的适配器；已经开始的会话拒绝更换世界拥有者；
- 跨隙 Runtime 集成测试不再手工传适配器，仍能完成后台规划和已验证动作交接，证明正式桥接使用共享世界；
- 剩余战斗问题已经写入 [B12 阶段方案](B12-partial-observation-combat.md)。

本轮没有重跑 C1 Fabric 场景。结论只覆盖组件和完整 Runtime 控制链，不新增游戏内成功率或时序统计。
