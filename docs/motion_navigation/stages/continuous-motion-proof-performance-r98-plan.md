## Task 4：P3 M3-lite 偏离闭环

建立只调用实验模块和项目 1.21 计算器的滚动闭环。每个 tick 先接收观察，再判断已有轨迹是否仍匹配，然后复用证明或从观察状态重算。偏离注入分别覆盖承诺前、承诺边界和承诺后。

本轮 P3 不经过正式 Runtime、仲裁器或客户端输入账本，因此性能只能称为“实验闭环决定耗时”。8／15／30 ms 在本轮作为进入正式适配设计的必要门槛；正式完整控制路径仍要在后续适配阶段重新测量。

闭环不能读取实验对象的私有字段，不能直接修改预测状态冒充观察。它使用实验侧的提交／实际应用账本记录每条输入；这不是正式 Runtime 账本，也不能据此声称正式账本链已验证。

通过条件：

- 安全违规、UNKNOWN 当空气、伤害超额、承诺后无新证明擅自换命令和无人负责输入均为 0；
- 所有等待、作废、重算和停止都有上限；
- 实验闭环决定满足 Windows 8／15／30 ms；
- 预计算作废率和重算分布完整报告；
- 与 D094、D093 和 D092 的冻结动作结果没有语义冲突。

状态连续量只允许 `1e-9` 绝对误差，离散字段完全一致。每个动作最多连续重证 3 次。同一 tick 内的查表、重证和许可构造按一次完整决定计时。承诺后发生超出证明范围的偏离时，旧锁定后缀自动失效，但原 owner 不能释放。闭环必须在当前决定内从真实状态取得新的恢复证明；取得前不得把旧后缀或中性输入写成安全命令。无法在期限内取得证明时，场景有界失败，P3 不通过。

### P3 实际结果

P3 建立了独立的滚动证明 owner 和实验提交／实际应用账本。它没有接入 Runtime、Session、正式客户端账本或 Fabric。证据修正后，模拟客户端每次推进都必须携带 owner、ledger、命令来源以及许可或时序分支身份。等待实际应用时，只能沿用已应用输入，或使用证明覆盖的在途输入；后端不再直接执行未提交的中性输入。

每个控制 tick 先消费应用记录，再计算动作阶段。连续量使用 `1e-9` 绝对误差，离散字段完全一致。同一 tick 内的账本处理、状态比较、许可检查、重证和结果构造全部计入决定时间；UNKNOWN 和失败路径也没有 0 ms 占位。

正式 Windows 矩阵包含 37 个场景，重复 3 轮，共 111 次运行和 1,338 个决定样本。

|---|---:|---:|
| P50 | 0.2521 ms | 报告 |
| P95 | 15.8503 ms | ≤8 ms，未通过 |
| P99 | 19.8099 ms | ≤15 ms，未通过 |
| 最大值 | 20.0919 ms | <30 ms，通过 |

精确按时、首条晚一 tick、转向后上一格和跨隙后行走都完成。跨隙后行走直接记录落地边界、落地速度和同一 owner 的下一条地面命令。目标修订场景把 `GoalState` 横向移动 1 格，不是只增加修订号。旧输入的两条时序终态都不满足新目标，因此承诺前返回 `candidate_terminal_goal_mismatch`，承诺边界和承诺后保持身体责任并失败；另有组件检查证明 0.01 格且旧终态仍满足的小修订可以重证。所有 1,227 次模拟后端推进都有 owner、账本和证明来源；伪造的推进 authority 会被拒绝。正常命令和四个变异都走 `RollingProofOwner.submit_through_gate()`：UNKNOWN 当空气、只证一条时序分支、删除落地证明和承诺后替换命令均未写入 ledger。

承诺后的恢复分母只包含确实需要恢复的 27 个运行。旧许可作废且同步取得新恢复证明才算恢复；本轮结果是 **0／27**。54 个承诺边界或承诺后场景无法生成恢复命令，明确结束为 `BODY_RESPONSIBILITY_UNRESOLVED`，并计入安全门槛失败，不能用“owner 仍保留”冒充安全完成。另有 6 个在承诺边界或承诺后晚到一 tick 的运行实际受到 11 点伤害，超过任务额度，也计为安全失败。

取消请求会持续保持到安全释放或明确的责任未解决终态。本轮没有构造出承诺后取消重证成功的样本；6 个承诺边界或承诺后取消均返回 `BODY_RESPONSIBILITY_UNRESOLVED`，没有继续旧后缀。应用窗口最后一个 tick 在该 tick 回执尚未摄取前仍可标记为 pending；摄取结束并关闭该 tick 后，同一观察会转为 missing，不额外推进一帧，也不补未证明的中性输入。

因此 P3 按预登记规则停止。P4 不实施，也不做内部状态构造优化。代码和失败证据保留，用于下一轮重新设计空中恢复入口与决定成本；不能据此声称正式控制链已经具备偏离恢复能力。
