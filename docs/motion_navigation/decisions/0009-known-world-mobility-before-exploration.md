# D009：先完成已知地形移动，再接未知探索

日期：2026-09-19
状态：已接受

## 要解决的问题

B05 之后，原计划准备进入未知区域探索和观察站位协调。但当前移动能力只覆盖普通步行和一个低速的一格上升动作。此时加入探索，会把“没有路”“不会走”和“缺少信息”混在一起，也会迫使搜索模块提前了解每种动作的特殊条件。

## 决定

交付顺序改为：

`B01–B05 基础闭环 → B06–B15 已知地形多能力移动 → 未知探索与观察协调 → 动态变化与局部绕行`。

B06–B15 只处理玩家自身运动。不使用载具或消耗型道具，不主动挖掘、放置或开关方块。每个阶段只加入当前需要的动作、几何或材质规则，不提前建立完整能力框架。

B06 先固定三件事：

1. 运行环境和证据来源；
2. 方块对运动的影响分类，以及普通完整方块共用的运动模型；
3. 目标状态、动作转换和路线资源标签。

后续动作都通过同一份动作转换契约进入规划、路线接纳和执行。不同动作仍保留自己的控制器和阶段，不能把具体动作规则塞进通用寻路器。

## 为什么这样做

已知地形能把信息获取从测试变量中拿掉。若某条路失败，可以直接判断是几何、能力、路线组合还是底层控制出了问题。

目标状态和动作转换先统一，后续新增冲刺、蹲行、跨隙、下降、攀爬和游泳时，就不必反复修改路线格式。普通材质先按运动效果归类，也避免为石头、泥土、木板和玻璃复制同一套控制参数。

## 影响

- B05 文档中“下一阶段进入未知探索”的旧说明改为指向 B06。
- 未知探索不属于 B06–B15 的完成条件。
- B06 的普通材质推广只覆盖实测过的完整方块。冰、灵魂沙、蜂蜜块、流体、可攀爬方块和危险方块仍返回未支持或延后处理。
- 旧的 B03/B05 Profile 和证据保留。B06 使用新 Profile ID，并绑定固定环境身份。
