# D007：B03 不使用不相容的旧版耗时比值

日期：2026-09-18
状态：已接受

## 要解决的问题

原架构给 B03 设置了一个初始门槛：固定路线完成时间中位数不超过有效旧控制基线的 1.15 倍。但 B01 固定的 `pre-floating-7ab0b35f` 只有源码摘录和探索迷宫成绩，没有可启动的同路线固定控制入口。

迷宫用时包含感知、探索、搜索、检查点选择和执行。拿它与只执行外部路线的 B03 比较，无法说明控制器变快或变慢。

## 决定

B03 不计算这个相对比值，改用已经定义的绝对门槛完成验收：到点误差、终速、途中低速、碰撞和越边、取消、输入断流以及每帧控制耗时都必须通过。

`pre-floating-7ab0b35f` 继续用于审查旧控制算法和比较整体运动体感。以后如果建立了同地图、同路线、同观察权限、同客户端版本的旧控制适配器，可以补充相对成绩，但它只增加证据，不改变这次验收的原始结果。

## 为什么这样做

缺少公平分母时，保留一个数字门槛只会鼓励选择不相容的旧成绩。绝对门槛能够直接回答 B03 关心的问题：固定路线执行能否独立、连续、安全地完成，以及计算是否落在控制周期内。

## 影响

这项调整只改变 B03 的验收方法，不改变三版参照身份，也不降低行为和安全要求。后续 B04 的规划性能必须另外定义自己的基线，不能沿用 B03 的控制耗时。
