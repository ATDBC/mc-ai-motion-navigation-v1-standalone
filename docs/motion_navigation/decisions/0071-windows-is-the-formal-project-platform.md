# D071：Windows 是项目正式环境

日期：2026-10-06。状态：已生效。

## 1. 决定

本项目的正式开发、自动验收和 Fabric 实机环境是 Windows。

三方审查使用 Linux，是审查方的环境限制。Linux 复跑用于发现可移植性问题，不再作为阶段关闭条件。除非用户或后续设计决定明确要求支持 Linux，否则缺少 Linux 结果不能阻塞开发。

## 2. 对 S0-R 的修正

D070 曾把 Windows 与 Linux 逐项一致写成 A1、A7 的共同门槛。这个门槛超出了项目范围。

修正后：

- A1 只要求 Windows 正序、逆序完整检查通过；
- A7 只要求五组行为集合在 Windows 连续两次一致；
- Linux 结果单独记录，不参与 S0-R 是否完成的判断。

S0-R 已在 Windows 满足 A1—A9，因此阶段完成。S1 可以开始，但本决定不自动启动 S1。

## 3. 证据边界

既有 Linux 复核结果继续保留。`post-f1-structure-s0r` 证据包也保持原字节，不回写当时的门槛说明；现行阶段状态以本决定、阶段文档、验收文档和 `AGENTS.md` 为准。

如果以后正式支持 Linux，应另行冻结依赖、运行命令、平台差异和验收范围，不能直接把三方审查环境当成产品环境。
