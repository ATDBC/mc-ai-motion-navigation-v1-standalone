# D003：导航通行几何与具体方块视觉分开

日期：2026-09-18
状态：仅保留为诊断原型；正式新主线的空气语义由 D004 取代

## 要解决的问题

旧感知只能可靠记录真正看见的实体方块。空气与被遮挡的未知空间难以区分，悬浮墙后方地面容易被误判成可到达位置。

## 决定

导航层可以在相机当前视锥、16 格距离和已加载区块内查询匿名通行几何，不受前方方块遮挡影响。它只返回：

- 空气；
- 无碰撞的非空气空间；
- 有碰撞的空间及碰撞形状；
- 查询未完成或区块未加载形成的未知。

导航层不返回方块 ID、注册名或物品身份。具体识别仍由原视觉系统负责，并继续遵守真实遮挡。玻璃在导航层中是有碰撞障碍；视觉层识别为玻璃后可以继续观察其后方，但不能因此把它改成可通行。

## 实现边界

采样包必须显式声明实际处理的范围和是否完整。只有确实处理的格子才能成为已知空气或已知占用。视锥外、距离外、未加载区块和预算未完成部分保持未知。

导航几何和视觉身份是两份数据。后续即使共享区块缓存，也不能用匿名导航结果补出墙后方块身份。

## 后续变更

实机可视化证明该方案性能足够，但用户随后确认正式机器人不采用整视锥透视。D004 改为：方块沿用 `pre-floating-7ab0b35f` 的合法可见事实，空气只在扫掠或支撑确实需要时批量确认正例。本文实现只作为诊断工具保留，不能作为 B02 正式世界知识的输入。

## 原因

寻路只需要支撑、净空、碰撞和介质信息。把具体材质识别绑进通行判断，会让遮挡问题反复进入规划。分开后，悬浮墙的头部障碍可以提前进入通行判断，同时仍保留寻找矿物时的真实视觉限制。
