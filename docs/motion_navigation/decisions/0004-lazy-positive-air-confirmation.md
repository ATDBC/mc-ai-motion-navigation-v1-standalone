# D004：空气采用按需批量确认

日期：2026-09-18

状态：已接受；2026-09-27 部分可见判定已实现，受影响的实机证据正在恢复

2026-09-26 补充：本文只决定空气如何按需确认，不再允许实现自行选择方块视觉来源。正式方块视觉必须使用 profile 4 表面深度。profile 3 稀疏射线已经弃用，只能读取历史证据，详见 [D035](0035-formal-surface-depth-only.md)。

2026-09-26 的实现曾要求目标整格完整可见。这个限制追求隐藏世界真值上的零误判，却改变了本决定原本允许的视觉误判。它还会让悬崖、坑、半砖和楼梯下方的必要空气永远无法从上层确认。2026-09-27 起，这条限制被下文的“有效露出区域”规则取代。修正方案见[视觉空气部分可见修正计划](../stages/B12-visual-air-partial-visibility-correction-plan.md)。

## 要解决的问题

profile 4 能提供真正看见的方块表面，但“没有报告方块”本身不能证明该格是空气。目标格可能在视野外、被其他方块完全挡住，或者所在区块尚未加载。

另一方面，真人不需要看见一个立方体的所有面，才会认为眼前露出的空间是空的。若假想完整方块的一部分本应出现在当前视野中，而这部分没有真实方块表面，机器人可以形成“这里看起来是空气”的判断。这个判断允许与隐藏的实际方块不同，并由后续观察或接触纠正。

## 决定

新主线使用 D035 固定的 profile 4 表面深度作为方块事实来源。空气由单独的正式观察能力按需确认：

- 调用方一次提交一组位置或一个扫掠体积，不逐格跨模块调用；
- 不主动扫描整个世界，也不因一个格子进入视野就自动查询；
- 每个观察请求最多提交 128 格，序列化请求最多 16 KiB；剩余位置留到后续帧；
- 空气候选与方块表面使用同一次相机姿态、同一个场景代次和同一份遮挡结果；
- 候选所在区块必须已经加载，候选位置必须位于 16 格范围内；未加载、超出范围或没有本帧覆盖证据时保持未知；
- 对候选格投影一个假想完整方块。裁掉视野外部分和更近遮挡面后，只要还剩大于几何误差阈值的可见区域，就说明该格有有效露出区域；
- 本帧若没有在该格报告真实方块表面，也没有身体接触或当前交互目标等更强事实，就可以返回视觉空气；
- 假想方块完全在视野外或完全被遮挡时，不能确认空气。没有返回的位置仍是未知，调用方不能据此反推出隐藏方块；
- 同一帧看到真实方块、身体接触到方块或当前交互目标确认方块时，不得为同格增加空气事实；
- 已经知道某格是半砖、楼梯等非完整方块时，普通的部分可见空气不能覆盖这条历史。要撤销这类方块，必须确认它原有的可见外形已经消失；
- 屏障、光源方块、结构空位等没有正常可见外形的状态，可以被判断为视觉空气。机器人接触到实际碰撞后，再由接触事实纠正；
- 角色身体碰撞盒实际占据的空气格不需要查询，随同身体事实直接确认；脚下支撑仍按实际接触形状确认；
- 已确认空气按世界会话缓存。世界会话变化立即清空；后来取得的合法方块、身体接触或交互事实可以覆盖旧空气事实。

视觉方块、视觉空气和未知是三种不同状态。未知不能用于通行授权。视觉空气表达机器人根据合法视野形成的判断，不是读取隐藏世界得到的绝对真值。

## 具体例子

一个半砖的实体部分被墙完全挡住，只有该格剩余的空白部分露在外面。假想完整方块在露出部分本应形成投影，但本帧没有真实表面，因此机器人可以暂时把该格判断成视觉空气。若机器人后来看到半砖或身体撞到半砖，新的事实会纠正这条记忆。

如果机器人以前已经看见并记住该半砖，则不能因为这次只看见它上方的空白，就把半砖记忆删掉。

悬崖下方紧贴崖壁的格子不可能从上层完整可见，但它通常有一部分远离崖壁的区域能够露出。新规则允许这部分合法视野产生视觉空气，因此下楼梯、下半砖和受控下降不再被“必须看完整格子”永久阻塞。

## 为什么这样做

扫掠、支撑和普通地面预测能够提前给出接下来一小段动作需要的格子。按这个集合批量确认，可以在控制器行走当前已知区域时准备下一段，同时避免逐帧扫描整个视锥。

表面深度已经计算了本帧所有遮挡面的投影。空气确认复用这份结果，把假想完整方块的投影减去视野外区域和更近遮挡面。只要剩余区域不是零，并且同格没有真实方块表面，就形成视觉空气。这里不再发射中心射线或固定数量的采样射线，也不要求整格全部露出。

验收不再追求与隐藏世界真值相比的“视觉空气零误判”。新的硬门槛是不能取得当前视角不可能获得的信息：未加载区块、视野外位置和完全被遮挡的位置都不能产生空气。隐藏的非完整方块造成视觉误判属于允许行为，但必须能够被更强事实纠正。

## 边界

空气确认是视觉正例接口，不是任意方块查询接口。它不能返回隐藏方块的类型、碰撞形状或“确定不是空气”。方块仍须由合法视觉、身体接触或交互事实获得。

确认结果可以像人的观察记忆一样过时。正式链要按当前路线依赖低频复查相关格子，但不能使用隐藏的方块变化通知提前撤销事实。执行层仍要处理碰撞和接触纠正，不能把视觉空气解释为永远不会碰到东西。

完全遮挡与视野外需要使用不同的等待原因。当前站位无法取得信息时，导航必须有界地返回“需要更换观察位置”，不能无限等待。自动寻找观察站位属于后续探索协调范围，不在本决定中提前实现。
