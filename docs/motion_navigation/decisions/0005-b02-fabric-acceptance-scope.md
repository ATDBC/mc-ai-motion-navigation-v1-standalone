# D005：B02 实机门槛采用独立 Fabric

日期：2026-09-18
状态：已接受

## 要解决的问题

B02 的目标是固定新运动核心的数据和几何语义。当前实际机器人运行在独立 Fabric 客户端，近期也不使用 CraftGround 做学习。若把两个后端的完整实机环境都设为阶段门槛，CraftGround 的构建环境问题会阻止已经可在正式运行端验收的工作进入下一阶段。

## 决定

B02 的实机门槛只要求独立 Fabric。CraftGround 继续遵守 Observation V3 和动作契约，并通过传输、配方和共同适配器的自动测试，但本阶段不要求启动真实 CraftGround 游戏实例。

这项决定只改变 B02 的验收范围，不删除 CraftGround 后端，也不允许 Fabric 和 CraftGround 拥有两套导航语义。以后确实需要 CraftGround 训练、并行评测或运行时，再单独恢复它的实机验收。

## 影响

- B02 可以依据 Fabric 的空气查询、世界会话和运动轨迹证据完成。
- B02 文档必须明确标注 CraftGround 只有契约级证据。
- B03 固定路线步行先在 Fabric 上验收。
