# D011：先建立确定性运动计算器，再做连续动作接续

日期：2026-09-20
状态：已采用

## 决定

在 B10 之前插入 B09-R。B09-R 只计算调用者给定输入的运动后果，并建立独立 Fabric 差分和性能基线。它不搜索输入，不选择路线，不接管控制，也不改写 B09 的历史验收。

物理计算器和运动预测适配器分开：计算器只接受完整、同版本的状态；适配器负责从正式观察和明确假设构造状态，并在字段缺失或来源冲突时拒绝计算。

## 原因

旧实现把参考轨迹、动作控制和有限的位移估计分散在多个能力中。直接做 B10 会继续让每种动作各自猜测制动、空中惯性和接触结果，也很难判断衔接失败来自控制还是物理模型。

先固定单 tick 规则，可以让后续模块共享一把尺子。B10 只需决定何时交接和短时采用哪条轨迹；B11–B13 逐项扩展特殊接触、攀爬和水中规则，而不用复制基础重力、碰撞和时钟。

## 影响

- B10 可以调用计算器评估已给定候选，但输入求解和候选排序仍属于局部规划或能力求解。
- 新计算器先以离线和只读影子方式使用。获得在线动作许可前，需要对应能力自己的安全验收。
- 规则不支持时必须返回明确结果，不能退化成普通地面继续算。
- 性能不足时先调整候选数量、预测长度或实现，不修改物理公式来换速度。

B10 后续实施已经由 [D012](0012-b10-staged-motion-solving.md)进一步拆成状态／输入基础、单动作求解和连续在线执行。D012 不改变本决定对 B09-R 计算器边界的约束。
