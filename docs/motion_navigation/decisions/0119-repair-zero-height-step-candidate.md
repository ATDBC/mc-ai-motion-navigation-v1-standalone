# D119：按原版规则恢复 0 高度 step 候选

日期：2026-10-19。状态：**COMPLETED。**

## 1. 要解决什么问题

D118 的有效 Windows 朝南 smoke 在 `fallback-back-south-0` 的 movement tick 246 发现一个确定的物理差异。该帧开始时：

- 身体位置为 `(14.5, 0.0, 29.505511702072333)`；
- 身体 AABB 的 z 范围为 `[29.205511702072332, 29.805511702072334]`；
- `(14, -1, 28)` 和 `(14, -1, 30)` 是完整草方块；
- `(14, -1, 29)` 是已观察确认的空气；
- 输入为后退，不跳、不潜行、不疾跑。

项目计算器先得到向下移动并撞到 `z=28` 方块侧面的基础解，然后在收集 step 高度时用 `height > epsilon` 排除了高度 0。它因此错误报告离地和水平碰撞。原版会保留高度 0，只排除与基础 Y 位移相同的候选；该候选保持 `y=0` 并完成全部水平位移。它给出的状态与 Fabric 只差约 `1e-8`。

这不是夹具、分析器起点或验收容差问题。独立逐 tick 对照只有 tick 246 不一致；后续连续回放的差异都是从这一帧扩散出来的。

## 2. 本轮决定

只修正 `physics_1_21` 收集 step 候选的规则：

1. 高度 0 是合法候选；
2. 排除的是与基础 Y displacement 相同的候选；
3. 0 高度候选不产生 `step_up` 事件；
4. 其他碰撞轴顺序、加速度、阻力、epsilon、UNKNOWN 和材料规则保持不变。

实现不能为 D118 trial、后退输入或某个坐标增加特判。该规则属于 Minecraft 1.21 的通用碰撞语义。

## 3. 验证顺序

先用 D118 tick 246 写 RED，确认旧代码得到错误的离地／水平碰撞结果。然后做最小实现，并按以下顺序验证：

1. tick 246 的位置、速度、着地、碰撞和 contact event 与已封存 Fabric 证据一致；
2. 只读重放现有 D118 raw run，确认原来的单帧分叉消失；
3. 复跑 B09-R physics step／rollout、ground traversal、motion solver／候选和 D118 检查；
4. 核对冻结离线表和原有成功结果；
5. 生成并验证独立公开快照。

现有 D118 失败记录不回写，也不运行新的 Fabric。

## 4. 授权范围

本阶段允许修改：

- `mc2p/motion_nav/physics_1_21.py`；
- 直接覆盖该语义的物理测试；
- D119 的决定、计划、验收、台账和打包入口；
- 为只读重放和公开导出产生的本地临时结果。

本阶段不允许：

- 修改 D118 固定输入、fixture 或 B09-R 容差；
- 启动 D118 四方向 full matrix；
- 开始连续两跳、prepared 自动后继或任何生产新能力；
- 顺手调整其他物理规则；
- 重新生成离线表来掩盖无法解释的变化。

## 4.1 实施结论

修复已完成。候选高度、普通碰撞结果的 Y 位移和最大台阶高度先按 Java `float` 取值，再按原版的精确条件筛选：保留 `height >= 0`，排除 `height == baseY`，并限制 `height <= stepHeight`。现有落地帧先下移候选基准的顺序没有改变。0 高度候选可以改善水平移动，但不会发布 `step_up`。

D118 的原始 Windows 记录已只读重放。7 个 trial、273 个 tick 的离散差异为 0；最大位置误差约为 `1.97e-6` 格，最大速度误差约为 `7.92e-8` 格／tick。旧 `fallback-back-south-0` 的 tick 246 分叉已经消失。

一项历史测试原先固定要求 seed 163 进入空中 `NEEDS_STATE`。修复后，计算器能证明机器人在地面潜行后退是安全的，因此不再进入那条故障路径。测试已拆成两个明确用例：正常场景必须实际应用地面恢复输入；当地面恢复明确不可用时，真实 worker 仍必须保持身体责任到落地、重锚和最终释放。两条路径都通过。

D119 只关闭 `D118-PHYSICS-01`。D118-0 的历史状态仍是 FAILED／STOPPED；第二跳入口包络仍未验证，D118-1—D118-5 仍未授权。

## 5. 停止条件

出现任一情况立即停止并记录：

- 除已知 tick 246 分叉外又出现其他计算器／Fabric 物理差异；
- 任何旧成功变为失败；
- 冻结离线表、输入哈希或行为签名发生无法由 0 高度候选解释的变化；
- 修复需要改变碰撞轴顺序、全局 epsilon、UNKNOWN 或材料规则；
- 两轮限定修正后仍不能关闭 RED；
- 需要扩大到 D118 full matrix、连续两跳或生产新能力。
