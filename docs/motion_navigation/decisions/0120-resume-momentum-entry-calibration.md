# D120：恢复带动量入口校准，先验证有限覆盖

日期：2026-10-19。状态：**COMPLETED；分阶段校准及发布门禁均通过，授权仍限于校准。**

关联：[实施计划](../stages/d120-momentum-entry-calibration-plan.md)、[验收](../acceptance/d120-momentum-entry-calibration.md)、[D119](0119-repair-zero-height-step-candidate.md)。

## 1. 要解决什么问题

D119 已修好原版 0 高度 step 候选。下一项未知是：第一跳真实落地后，下一拍继续跳或潜行停住，能否容忍实际位置、速度和朝向的误差。原 D118 的单条潜行轨迹停住了，但最终脚印重叠只有约 0.000551 格。这不能直接证明入口没有容差，也不能证明入口足够宽。潜行在边缘按离散步长减小位移，必须实际扰动入口再推演。

## 2. 本轮决定

先固定有限入口样本，再运行旧 raw 只读门禁、朝南三场和四方向 36 场。每一步通过才能扩大。通过只说明冻结样本和实机记录符合校准条件，不宣布四格跨隙或连续跑酷已成为生产能力。

有限入口覆盖指逐项计算一组提前登记的位置、速度、朝向组合。它不证明组合之间的每个实数状态都安全。输出必须分别保留 `sample_coverage` 和 `sound_envelope`；后者保持 `unverified`。未来生产接入仍须从真实入口完整重证，不能查到包围盒就放行。

## 3. 入口和时序

入口绑定第一跳 authoritative landed 事件的 **post-state**。落地 tick 记为 L；不得拿 L 的 pre-state 或另一次落地冒充。

三族分别为：

- `landing-immediate`：第二跳在 L+1 生效；
- `landing-immediate-late1`：先按固定 RUN 输入保持一 tick，第二跳在 L+2 生效；这是固定时序对照，不是网络晚到注入；
- `fallback-sneak`：潜行在 L+1 生效，完整尾迹留在中间平台。

三族都必须通过冻结的离线目标；不能在运行后把 L+2 从正例改为负例。旧 neutral/back 只作为离线失败对照，不重复跑无关 Fabric。

入口记录联合的位置 x/z、水平速度 vx/vz 和 yaw，同时绑定 y、vy、着地、姿态、身体尺寸、疾跑/潜行状态、规则版本、世界、输入和时序身份。不能把独立维度的极值拼成未经计算的安全矩形。yaw 在 raw 中是角度，进入计算器前必须转成弧度。

## 4. 覆盖和误差口径

入口样本以计算器从冻结第一跳得到的名义 landed post-state 为中心。联合格点固定为：本地横向和纵向位置各取 `-0.002／0／+0.002` 格，水平横向和纵向速度各取 `-0.0002／0／+0.0002` 格/tick，yaw 取 `-0.1／0／+0.1` 度，共 `3^5=243` 个组合。y、竖直速度和离散状态不做不符合着地事实的人造扰动，必须与名义 landed 状态及真实支撑身份相同。枚举顺序、输入后缀、每个后缀最大 tick 和总物理步上限写入不可变清单，计算哈希后才能执行。失败后不得缩小集合换取通过。

分别报告入口扰动覆盖、入口相对登记边界的距离、潜行最终脚印重叠和每一帧的支撑。最终脚印重叠小于 0.001 格，不自动等于入口失败；要看加入已登记扰动后是否仍能安全收尾。有限点通过也不能替代连续范围证明。

真实 raw 落地状态进入格点的外接边界，只说明 `within_registered_bounds`。分析器还必须从该真实 post-state 分别重放三个后缀，输出独立的 `raw_suffix_replay`；不能把落在边界框内写成“已经由 243 个格点之一证明”。

物理对照沿用位置每轴 0.001 格、速度每轴 0.0001 格/tick。离散状态必须一致。以上值不放宽全局数值等价或动作接纳条件。

## 5. 授权边界

只增加校准脚本、直接测试、新清单、独立证据和文档。Fabric 包装器复用 D118 Runtime 循环，部署入口只接线，不另写输入出口。`mc2p/`、Session、规划器、求解器、Runtime 和 Java 协议不改。

先用 D118 原始目录只读验证朝南入口与身份链。通过后运行朝南三族各一次；再通过才运行三族 × 四方向 × 三次，即 36 场。每次正式命令显式给出 600 秒期限。捕获成功和验收通过分别报告。

D118 的 FAILED／STOPPED 和 D119 的 COMPLETED 保持原历史结论。D118-1—D118-5、prepared 自动后继和生产新能力仍未授权。

## 6. 止损

出现损伤、UNKNOWN 被当作空气、输入身份不明、owner 空档、真实期限错过、物理离散差异或无界等待，停止扩大。离线失败不跑 Fabric。当前范围最多两轮限定修正，全部失败和 INVALID 记录保留。

若必须改变固定输入、生产策略、全局容差、输入协议或世界语义才能过关，本阶段停止并说明原因。不得用墙钟改变采样或可行性结论。性能只报告实际工作量与耗时，不在运行时新增搜索。
