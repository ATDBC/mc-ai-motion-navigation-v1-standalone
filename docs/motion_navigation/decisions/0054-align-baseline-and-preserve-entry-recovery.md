# D054：先核对当前基线，入口变化与身体收尾分别处理

日期：2026-10-03。

D052／D053 的跨隙和接续专项不能替代完整 R28 比较。进入 R28-1 前，保留 v4 的二千项输入，以同一外部量尺另存当前结果；原基线和失败记录不改写。

这轮预检通过后，完整比较仍发现下降组退步。其中一个任务在输入失联后停在上层边缘，脚下支撑只有约 0.64%。动作执行器已经返回失联，监督者又不能按原 1% 支撑门槛释放身体，双方一直等待。扩测随即停止，已完成的二千项产品记录和七百项协调记录保留。

按两个现有拥有者修正：

- 后台复核返回 `NEEDS_STATE` 且当前朝向未对齐时，可以消耗现有重试额度后重新对齐与求证。依据实际朝向判断，不解析原因文案。当前速度、姿态等必要条件的拒绝不因此获得无限重试；硬冲突、未知、算不完保留原分类。
- 路线业务结束后，原执行器仍负责身体。当前中性输入的停止尾迹不能通过原释放门槛时，使用已有计算器逐帧证明潜行退回更大支撑的输入。身体安全后再由监督者释放。业务终态、伤害额度与释放门槛均不放宽。

普通地面若已绑定当帧战斗视角，退回也使用同一获胜朝向计算。复用原 `movement_yaw_radians` 和视角仲裁条件，不创建第二套恢复视角。三个朝向反例检查实际应用后的支撑必须增加。

这两处不添加 Session 状态、私有等待账本、进程或动作组合表。无法证明退回输入时，不能伪造安全释放。正式回归同时覆盖视角变化后的后台复核，以及坑边失联后的实际输入、支撑、终态和来源释放。

测试夹具另有独立遗漏：交错投递旧结果后，没有继续服务新提交的后台复核。夹具应真实执行后续任务，保留故意不服务的负对照。比较工具核对这项修改确实是已登记的夹具差异，不修改旧源码哈希，也不忽略其他差异。

当前比较用于记录差异和定位问题。固定样本不能签署统计发布门槛；有界失败也不能计为成功。最终数字、未关闭项和实机边界只维护在 R28 验收第 13 节。
