# D076：路线优化前统一目标完成区域

日期：2026-10-08。状态：已接受并实施任务 0—2。任务 3 首版正式量尺漏计 Runtime 外壳，但其跟随目标修订帧 P95 `8.6204 ms` 是完整生产耗时下界，仍超过 `8 ms`。量尺已修正；非正式 77 修订帧诊断为 `8.8566 ms`。F2-S 按本决定第 6、9 条停止，没有重跑正式 4096；任务 4 和 Fabric 未运行，阶段未关闭。

## 要解决的问题

F2-R 修复了障碍物把目标切成 L 形时的原地拒绝。平台外角、桥头和柱顶仍有同类问题：目标内存在安全站位，但完成区域的一个顶点支撑比例低于 `0.5`，整个区域因此被拒绝。

当前还有三处设计偏差：

1. Session 用点查询选支撑面，规划尾段和接纳再用区域查询。同一个目标会先被选中，随后才被拒绝。
2. 障碍和支撑分两轮裁剪。安全矩形能否跨过两个相邻块，取决于前一轮怎样切块，而不是取决于真实几何。
3. 路线复核重新寻找全局最优区域。没有进入路线依赖的远处变化，也可能让原本仍安全的路线失效。

区域查询也位于跟随目标修订的控制路径上。若 Session 对目标内每个支撑面都运行一次精确查询，杂乱地形可能超过控制期限。

## 决定

1. `standable_region_in_goal()` 负责首次选择完成区域。Session、需要真实终点的规划尾段和路线接纳共用这一个结论。`surface_overlaps_region()` 只保留为便宜的必要条件，不能授权执行。
2. 障碍边界、UNKNOWN 的最坏占用边界和支撑形状边界进入同一张二维网格。每个单元同时判断净空与支撑。算法从全部合格单元中选择面积最大的连续轴对齐子矩形，不再先切障碍块、再分别裁支撑。
3. 网格边界已经包含碰撞边界，因此单元内部的阻挡状态不再变化，可以用单元内部代表点判断净空。支撑比例在单元内是双线性函数，四个顶点都不低于 `0.5` 才能证明整个单元合格。UNKNOWN、危险材质、流体和未支持形状继续沿用现有类型化结果。
4. 目标完全落在一个支撑网格内，而 `0.5` 门槛切面穿过该网格时，本阶段仍返回 `UNSUPPORTED`。不引入二分求根，也不接受零余量站位。
5. Session 先用不读取精确区域的稳定键给候选支撑面排序，再顺序查询。找到第一个完全已知的可行区域后立即停止。之前候选的缺信息只在最终没有可行区域时汇总。一次选择共用一个 `WorldQueryCache`。
6. 排序、查询数量和返回语义不能依赖墙钟。F2-S 在 Windows RED 阶段固定“首个可行、最后一个可行、全部不可行”三类最坏耗时。正式修复若仍超过冻结的最大值门槛，本阶段停止，另写决定把查询移到后台或跨帧执行。
7. 初次选择和后续复核使用不同接口。初次选择寻找当前最合适的矩形；复核只验证已绑定矩形仍位于目标内、净空、支撑合格，而且支撑面身份没有变化。复核不能重新求全局最优区域。
8. 选定矩形后，只把该矩形的净空、支撑、支撑面身份和真正定义其边界的 owner 写入执行契约。放弃区域出现更优站位，不会让当前安全路线失效。
9. D061 分别报告生产控制耗时、模拟后端耗时和完整夹具耗时。生产准备继续要求 P95 `≤ 8 ms`、P99 `≤ 15 ms`、最大值 `< 30 ms`；完整夹具保持 `≤ 50 ms`。区域选择另设 Windows 数值门槛，该数值必须在 RED 后、修改生产代码前冻结。
10. v8 的 `41` 项无已知路线使用独立、有界的参考搜索。参考搜索不能复用 `known_map_planner` 的节点扩展或代价。只有独立模型覆盖玩家连续配置空间并穷尽搜索时，才可标记不可达；方块中心四邻接搜索穷尽或预算用尽都只能标记 `UNRESOLVED`。
11. v9 额外报告“存在站立点但正式任务失败”的数量。它用于发现规划和执行缺口，不作为 F2-S 关闭门槛。
12. F2-R 保持关闭，原 v8 和失败记录不回写。本决定通过新的 F2-S 小批次实施，通过后再开始路线优化器。

## 不修改的边界

- 不改 ExecutionSupervisor、PlanningCoordinator 和 Runtime 的生命周期、责任交接或输入权限；
- Session 只修改目标选面查询，不新增状态、等待、重试或动作分支；
- 不改中心点搜索，不实施路线平滑，不启用正式潜行区间；
- 不改身体宽度、支撑比例、危险材质、UNKNOWN 或停止尾迹门槛；
- 不删除或重新解释 v8 的无路和执行失败；
- 动作接口继续冻结，路线优化器不作为新动作的扩展探针。

## 影响

F2-S 会新增支撑边缘量尺，并把 v8 中 `9` 项无前进控制、`5` 项停滞和 `41` 项无已知路线登记为路线优化阶段的参照。区域选择的性能证据会覆盖跟随目标修订，并同时记录首个、最后和无可行候选三种情况。

主项目继续保留旧 M0–M1 计划作为隔离历史。整理后的公开快照不再导出该计划；正式结论只保存在四类运动导航文档中。行尾治理继续留给独立的纯格式提交。
