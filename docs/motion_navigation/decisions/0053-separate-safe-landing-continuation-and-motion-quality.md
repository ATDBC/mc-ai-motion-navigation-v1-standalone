# D053：分开安全落地、后续要求和运动质量

日期：2026-10-02。状态：共同出口、限定直线跨隙择优及连续高度尾段已实施；结果见验收第 12.8 节。沿用 D048、D051、D052 和现有 R28。审查事实与边界见[验收第 12.7 节](../acceptance/navigation-coordination-convergence.md#127-动作效率与共同出口审查)，实施顺序见[阶段第 9 节](../stages/navigation-coordination-convergence-r28-plan.md#9-共同出口与运动质量修正方案)。

## 为什么改变

本轮跨隙已能带速起跳、落地后继续走，但实际输入仍是起跳后后退两帧，再松键滑行。三类空中动作把单块目的支撑面当作整个候选的出口；后继只提供方向和一帧前进。求解器找到第一个合法模板就返回。连续高度段接非格心尾段也仍会先停稳。

这些限制分别落在规划、求解、控制和确认中，单改一个落点半径不能统一解决。当前方案已经写了连续运动目标，实际接口尚未把这个目标完整传递下去。

## 决定

1. 安全条件决定候选能否采用。任务和后继动作决定需要什么出口。效率在通过安全检查的候选中比较。
2. 全局图继续选择通道。局部运动可以落到这条通道上的其他已知安全位置；支撑格代表点不自动成为必须停到的物理目标。
3. 落地确认、正常出口和中断恢复分别检查。它们使用同一份真实几何和身体事实，但不要求落在同一块方块内。
4. 空中求解、地面证明、接纳、执行和恢复确认消费同一份后续要求。单块旧出口、默认停稳和固定一帧前进不能继续各自解释同一个接续。
5. 运动质量主要比较相同任务和后续要求下的用时、进度、必要减速及反向输入。身体速度、采样位移速度和输入空档分别记录，不用某一个数字代替体验。
6. 候选数量和排序确定、有界。复杂证明留在已有 worker；不能用墙钟算完了多少候选决定目标或支持范围。

## 保留的边界

原能力入口、真实姿态、视角、未知空间、输入窗口、任务伤害额度、完整轨迹和中断恢复检查继续有效。旧低速 Profile 保留为后备。扩大出口和改变真实按键属于行为修改，必须生成新证明和相关世界依赖；旧证明不能在接纳时偷偷换条件。

不新增全局速度状态格、通用 MPC 框架、第二套控制者或运动物理。游泳、攀爬、全面混模式、自动转身及新疾跑能力不借本轮开放。

## 对阶段的影响

J1—J4 的验证条件、后台复核和连续交接结果保留。J5 首个试点只证明执行链和对应安全条件成立，运动质量门槛继续打开。既有 914 项检查、四方向 Fabric 4/4 和失败归档不改写。

本轮改变了实际输入和出口范围，按行为修改记录，不算行为不变迁移。后续每次改变输入或支持域仍按 R28 原规则登记影响层和正式批次；不能把行为修改算成行为不变迁移，也不能用本方案名称自动延长时间盒。先交付有限直线跨隙的共同出口与择优，再按影响逐项接入已有升降和地面段。

## 实施后的澄清

恢复和正常完成使用同一份不可变要求，但条件不同。正常出口满足完整后继入口；输入失联后，允许确认真实、已知、净空成立且支撑比例达到原地面 0.15 门槛的部分支撑着地。这个确认只接普通地面闭环，不把一次着地当成旧输入回执，也不授权新起跳。

原恢复 R tick 是到达着地低速安全收尾条件的期限。新增被动尾迹证明必须一直算到真实水平零速度，总推演最多 2R。原恢复资格、动作窗口、正常二十 tick 上限和伤害额度不变。

十二个跨隙候选内替换两项持续前进模板。共线参考点不再限制出口，执行器从实际出口移除已满足的参考点；拐角、严格动作和证明段不能被跳过。上升和下降已消费共同出口，但保留原有限模板和首次合法选择；完整新组合与实机扩验仍未关闭。

拐角提前松键和无害墙接触继续按 D051 单独实施。R28 的共享恢复、任务预算、异步收敛和正式跟随仍是主线，不因本轮质量改善而记为完成。
