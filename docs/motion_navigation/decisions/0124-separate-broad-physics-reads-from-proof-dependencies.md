# D124：区分计算器宽查询与证明必要依赖

日期：2026-10-21。状态：**COMPLETED／SIGNED**。D124-0—D124-3 与完整 Windows 发布门禁均已完成；本阶段没有运行 Minecraft／Fabric。

关联：[架构](../architecture/proof-dependency-projection-v1.md)、[计划](../stages/d124-proof-dependency-projection-plan.md)、[验收](../acceptance/d124-proof-dependency-projection.md)。前序为 [D123](0123-resolve-proof-dependencies-and-transport-loss.md)、[D003](0003-anonymous-navigation-volume.md)和 [D004](0004-lazy-positive-air-confirmation.md)。

## 1. 要解决什么问题

D122 Fabric v8 的 67 个 proof 依赖只有 55 个 actor 已知，12 个下层格未知。D123-0 已说明其中 3 格确实参与父恢复或后继；另外 9 格有上方支撑，但宽 `BlockGeometry` 合同仍允许构造材料反例，所以没有批准删除。D123-1 又证明固定站位转头不足以补齐依赖，按门槛停止。

继续要求 actor 看见所有计算器宽查询格，会把不必要的信息需求当成观察能力缺口；直接删依赖又可能丢掉真实安全前提。D124 先处理两者之间的合同，不扩展观察权限。

## 2. 本轮决定

明确区分宽查询候选格、安全必要依赖和 actor 待观察事实。只有安全必要依赖进入 proof 和正式观察门禁。依赖必须在源查询按碰撞、step、潜行支撑、材料作用等用途收集；禁止在最终序列化、清单或 gate 上过滤。

先用真实 Minecraft 1.21 的形状与材料作用规则证明完整方块屏障。上方支撑本身继续作为必要事实绑定版本。下层保持 `UNKNOWN`，不生成空气事实；屏障前提失效后，下层依赖恢复。

首轮只允许完整方块屏障，不顺便推广半砖、楼梯和多盒拼接。真实必要的 parent、successor、fallback、release witness 和时序分支依赖全部保留。南向 `z=0、2、5` 的 3 格是必须守住的代表负例。

## 3. 为什么先查原版规则

当前材料检查遍历碰撞依赖，把碰撞形状盒接触用于拒绝非普通材质。碰撞盒范围与原版材料触发位置并不天然相同。D123 的两格高蜂蜜块说明当前数据合同过宽，不能直接作为“真实原版一定会影响”的证明。

但发现一个合成组合不存在，也不能证明所有真实状态都无关。D124-0 必须冻结原版来源、调用点和适用范围，覆盖未知格可能代表的真实状态上界。没有关闭的材料、流体或动态边界继续拒绝；不能把少量样本等价当作普遍结论。

现有 vanilla 注册表只列 ID，移动特征目录只登记效果，不能穷尽 `BlockState`、邻居和碰撞上下文产生的形状。D124-0 在现有 `PhysicsWorldView.__init__()`／`from_snapshot()` 入口明确每项适用前提由谁确认，并核对 world → sealed snapshot → worker request → proof 的身份链。现有数据不足以确认时停止，不能只认 Minecraft 版本标签，也不能再查询已省略格。

源查询候选与冻结宽查询 reference 独立对照，expected 不得由同一个新收集器产生。`0e6b0141` 的 parent-only、successor 完整安全 tail-only 依赖内容变化／`UNKNOWN` 撤销和纯 stamp 刷新检查必须具名保留；不能用新集合删掉旧见证来让测试失去区分能力。

## 4. 预期结果与替代方案

首选结果是证明这 9 个下层格在完整屏障下不再属于必要依赖，3 格继续要求观察。若只发生这项变化，67→58 是可解释的结果；它不构成 actor 门禁全绿，也不说明连续跑酷已经交付。

可替代路线是先只完成依赖分层、继续保留尚不能证明无关的格。它可以关闭合同歧义，但 D124 整体仍记 PARTIAL／STOPPED，不能计为观察问题已解决。改变观察站位需要以后另立范围，本轮不实施。

不选择全局禁止任意材料／形状组合来换取通过。这会扩大到观察、快照、旧数据和通用几何。D124 只明确当前原版证明规则何时适用；不符合条件时保持拒绝或保守路径。

## 5. 范围与停止

允许后续实施涉及 `geometry`、物理查询、材料作用检查、在线／prepared 支撑汇总，以及对应测试、探针、导出和文档；具体任务见计划。实现与完整发布门禁均已完成。

不恢复匿名或穿墙几何，不把 `UNKNOWN` 改成空气，不增加 viewpoint planning、worker 管线、Session 状态或输入出口。不进入 D123-2，不改 transport、Java、planner、伤害额度、支撑阈值和动作 profile。不启动新的 Minecraft／Fabric。

真实原版反例推翻屏障前提、适用范围无法清楚表达、必要的 3 格被删除、必须绕过最终门禁或需要扩大上述边界时，保留证据并停止。每批最多两轮限定修正，独立复核通过后才进入下一批。
