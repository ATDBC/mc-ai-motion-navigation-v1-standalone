# D037：连续高度移动改为证明走廊内闭环执行

日期：2026-09-27

状态：已接受；组件闭环和整改后的代表性 Fabric 矩阵已通过，完整矩阵待验收

## 决定

连续高度普通步行不再逐帧回放离线证明中的固定输入。

离线计算保留三项职责：证明这段地形可通行、给出安全走廊、冻结依赖和入口／出口范围。在线执行器每帧读取当前身体状态，在安全走廊内用同一个 1.21 运动计算器选择本帧输入。

地面证明按规划表面节点序列绑定。身体当前位置到第一个节点的短接入线属于执行问题，不改变证明所覆盖的地形段。

执行器离开证明适用范围或连续没有进展时，返回有类型的重规划结果。导航会话保留仍安全的身体责任并从当前位置重新规划；它不会因为普通地面跟踪偏差直接把整个任务判为失败。空中动作仍由原执行器负责到安全落地。

任务伤害额度按整项任务累计。规划中的每条受伤下落都会消耗余额。同一任务只修改目标时不补回余额。

多格下降还要满足近距离落点底部观察门槛。普通的“该格曾被确认为空气”不足以授权扩大下落范围。

落点被当前平台遮挡时，受控下降可以先潜行到仍有支撑的边缘观察。探边是获取证据的动作，不是新的路线目标。证据成立后，如果当前蹲伏身体仍在受控下降的已验证入口范围内，就从当前位置直接开始下降，不先回到格子中心。

动作完成按证明公开的出口条件判断。对受控下降来说，出口是一个落地区域以及速度、姿态和移动模式范围，不是离线模拟中的单个坐标点。实际落点只要仍在该区域内，就可以完成并交给下一段。

同方向连续两级及以上的一格下降视为一段连续地面穿越。规划器只在拿到当前入口状态后合成候选，并由 1.21 计算器验证整段。孤立一格下降、跨空落差和直接多格下落继续使用 `ControlledDrop`，不能继承连续阶梯的证明。

## 原因

固定输入回放只对生成证明时的精确起点、速度、视角和生效 tick 有效。真实运行会有厘米级起点偏差、一帧输入迟到和战斗视角变化。继续增加回放容差会让安全范围越来越难解释，也不能解决停滞。

逐帧重新计算只处理当前一小段，不改变全局路线，也不会引入新的大规划器。它复用了已经验证的运动计算器和九键控制集合。

## 边界

- 闭环控制只能在证明走廊和已知依赖内修正。
- 现场产生的新轨迹超出证明适用范围时必须重规划。
- 下落观察证据没有满足前，不得用任务收益抵消安全门槛。
- 只有“落点视觉证据缺失”可以触发探边。普通遮挡、超出范围和传感器不可用继续按各自原因等待或失败。
- 连续阶梯合成失败时必须回到已有受控下降后备，不能用未证明的普通 Walk 继续执行。
- 本决定不声明任意速度、任意视角或所有方块形状均已通过实机验收。
