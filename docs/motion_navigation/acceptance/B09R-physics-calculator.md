## 验收范围

本次验收计算器是否能复现已经给定输入的运动后果。它不验收自动寻找输入、自动到达目标或 B10 连续接续。

数值阈值在保留运行前固定为：连续开环每轴位置误差不超过 0.001 格，速度误差不超过 0.0001 格／tick；落地、离地、碰撞、实际冲刺和姿态等离散状态必须一致。

## 组件与失败边界

- 状态构造会拒绝缺字段、未知假设、观察与假设冲突及不同世界会话。
- 必需碰撞格未知时返回 `NEEDS_WORLD`，不产生部分后继状态。
- 水、攀爬、飞行、鞘翅、未知效果和使用物品减速返回 `UNSUPPORTED`。
- 撞墙、碰顶、落地和跨步是正常结果。
- 半砖、楼梯、地毯、积雪、负坐标、整数接触边界、潜行防跌落、按累计下落距离收窄的近地潜行、悬空墙排除、落地同 tick 跨步及起跳撞墙有直接组件测试。
- 单独释放冲刺键会在继续前进时退出冲刺；首次接触尚未建模的特殊材质会返回 `UNSUPPORTED`。
- 连续与保存恢复一致；分支互不修改；预算、取消和外部事件只在完整 tick 边界停止。完整和摘要输出都保留关键事件及累计资源完整性，完整输出另保留每个 `StepResult`。
- 关闭客户端产生的最后一次中立输入已纳入计时诊断，避免正式 trace 比诊断多一条观察。

### 2026-09-23 计时勘误

原脚本在正式计时前启动了 `tracemalloc`，因此上述吞吐包含 Python 分配跟踪开销，不能作为正常运行速度。旧结果保留，不删除或改写。

修正后的脚本把墙钟计时和峰值内存分成两遍运行，并在输出中记录 `timing_under_tracemalloc: false`、Python 版本、CPU 和预热次数。当前机器使用 Python 3.11.16、30 次计时和每组 5 次预热，得到：

| 范围 | P50 | P95 | 有效吞吐 |
|---|---:|---:|---:|
| 1 tick，1 个候选 | 0.0651 ms | 0.0727 ms | 15,361 tick／秒 |
| 20 tick，1 个候选 | 1.3091 ms | 1.3168 ms | 15,278 tick／秒 |
| 60 tick，1 个候选 | 3.9554 ms | 3.9701 ms | 15,169 tick／秒 |
| 20 tick，32 个候选 | 41.8121 ms | 41.8424 ms | 15,307 tick／秒 |
| 20 tick，128 个候选 | 166.5114 ms | 166.8912 ms | 15,374 tick／秒 |

独立内存遍历的 Python 跟踪峰值为 20,878 字节。它与旧版在计时循环中持续跟踪得到的峰值口径不同，只用于观察当前基准夹具的分配量。

勘误不改变 B10 的预算结论。32 个 20-tick 候选已经超过控制帧 P95 8 ms 门槛；128 个候选也超过 50 ms 提交期限。批量搜索继续放在有界后台任务中。

## 数据边界

按完整状态边界重新切分后，本轮形成 219 段逐 tick 开环差分序列。分段数增加来自更严格地识别位置、速度、姿态、视角、接触状态和 tick 连续性变化，不代表增加了新实机样本。
