## 验收口径

| 项目 | 判定 |
|---|---|
| 路线输入 | 只接收外部固定路线；运行中不自行搜索或插入检查点 |
| 到点 | 水平误差 ≤0.25 格，层高与支撑成立，水平速度 ≤0.1 格／秒 |
| 安全 | 可避免的碰撞、越过已知坑边和把未知当空气均为 0 |
| 顺滑 | 空地直线无中途低速；宽转角不在中间路点强制停稳 |
| 横向偏移 | 0.02、0.05、0.10 格初始偏移能平滑收敛，不先向后回拉 |
| 取消 | 先接纳取消，再按实测制动包络完成；未停稳不能报告已取消 |
| 输入确认 | 丢失实际应用确认后不继续推进阶段，进入 `INPUT_LOST`，再由正式动作出口提交中性输入 |
| 输入断流 | Fabric 租约到期自动释放按键，停止距离与持续 tick 有原始证据 |
| 控制耗时 | 纯控制 p95 ≤8 ms、p99 ≤15 ms、最大 <30 ms |
| 相对耗时 | 没有可启动的同路线旧版基线，不对不相容的迷宫成绩计算比值；按 D007 以绝对指标验收 |

低速片段沿用架构定义：活动导航中水平速度低于 0.1 格／秒并持续至少 0.15 秒。终点制动和已经接纳的取消不计为中途低速。

## 计划场景

- S00：空地直线、终点重合、重复末点；
- S01：宽转角与连续 Walk 接续；
- S02：窄转角，允许按已知空间必要减速；
- S03：任意水平视角和不同俯仰角下沿相同世界路线行走；
- S07：0.02、0.05、0.10 格横向偏移；
- 取消：不同初速度下取消并实测停稳；
- 确认丢失：上一帧输入没有应用确认；
- 断流：移动租约生效后停止发送控制。

## 旧版比较边界

`pre-floating-7ab0b35f` 保存的是源码摘录和探索迷宫成绩。它不是可直接启动的固定路线运行包，也没有同路线、同权限的完成时间。迷宫总时间同时包含探索、搜索和路线选择，不能作为 B03 执行层的公平分母。

D007 因此取消本阶段的强制相对比值，只保留绝对运动、停止、安全和控制耗时门槛。以后若建立可复核的旧控制适配器，可以追加比较，但不能倒改本次原始结果。

## 证据边界

- 本阶段只证明普通地面的外部固定路线步行，不证明 A*、探索、动态绕行或跨高度动作；
- 当前动力学只校准并允许本次超平坦场景的 `minecraft:grass_block` 支撑；其他材质返回 `UNSUPPORTED`，不能套用同一参数；
- 真实游戏的 50 条路线是五类确定场景的重复验证，不等于 50 张独立地图；100 组参数化组合属于确定性闭环测试；
- S02 已覆盖真实两格高 L 形墙体形成的窄通道；动态障碍仍留给后续场景验收；
- 墙边和坑边的软缓冲已进入候选评分，但复杂危险边界仍需后续阶段扩大实机覆盖。
