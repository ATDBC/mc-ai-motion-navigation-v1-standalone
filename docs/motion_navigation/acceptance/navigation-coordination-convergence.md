## 2. 五条安全规则

| 编号 | 阻塞条件 | 必须保存的依据 |
|---|---|---|
| S1 任务风险 | 机器人提交了超出任务授权的预计伤害或资源承诺；自身动作的实际伤害超出支持范围声明且没有正确处置 | 授权、预留、承诺、观察及伤害归因；外部攻击单列，不能承诺任意战斗中总扣血为零 |
| S2 行动依据 | 未知被当作空气；高风险动作缺当前有效证明或安全事实仍执行；低风险放行缺在线支撑、净空或尾迹依据 | 当前查询、证明／预测、依赖变化、接纳与真实应用记录 |
| S3 输入与责任 | 绕过唯一输入出口；原责任未交接就释放；身体责任结束后旧来源仍提交输入 | 来源、仲裁、应用、交接和释放后尾迹。业务终态后的必要收尾输入合法，不能一律禁止 |
| S4 无界等待 | 任务或恢复超过冻结上界仍无明确结果；通过改目标、刷新世代或伪进展延长预算 | 任务与恢复开始、预算消费、真实进展、终态及来源状态 |
| S5 错误处置 | 正式控制链发生未处理异常；吞错后继续；反复重建 Runtime 丢失身体责任或派发依据 | 原异常、失败分类、原控制者及安全收尾记录 |

这些是检查对象的归组，不能直接删掉旧 I1—I22。R28-5 提交映射表，说明每个旧检查由谁保留，哪些合法行为已经改变。缺记录表示证据不足，不等于零违规；关键证据不足仍阻止签署安全通过。

伤害归因必须有来源或环境证据。归因不充分时保守扣账或报告未验证，不能通过标为“外力”来豁免 S1。

任务预算用尽后不得开始新目标动作，原控制者仍可在冻结收尾窗口内完成必要落地或副作用确认。连接失效、长期没有身体观察或环境超出模型范围时，必须有类型报告控制不可用／身体未验证；不能写成安全释放。可控制的支持范围内，任务与身体收尾都须有界。

安全反例要给出一组同类扰动与正常对照，并做错误规则恢复检查。零违规仅表示冻结集合内未观察到违规，不声明任意环境安全。

## 3. 产品场景

| 场景族 | 范围 | 主要指标 |
|---|---|---|
| 指定点 | 平地、转角、已知迷宫／绕行、起点偏移；含高风险邻接的窄桥负对照 | 完成率、到达时间、停顿、恢复次数 |
| 连续高度 | 半砖、楼梯、土径、连续整格下降；直接多格下落另列严格组 | 完成率、衔接时间、停顿、额度和落点证据 |
| 移动目标 | 正式 C1／B12 导航驱动，覆盖目标远离、横移和频繁修订 | 目标确定到移动的时间、修订响应、移动中瞄准比例、停顿 |

每族有正常输入、20% 一 tick 迟到、有限外力与目标修订条件。事件可重复；身体阶段与中断组合按正式路径触发。未触发和跳过单列，不能替代覆盖。

产品随机比较以场景族及正常／扰动形成预先声明的主要分层，方向、速度和材质在层内平衡；直接严格下降另列，不能混入普通地面来稀释失败。不要求每个方向与材质组合都运行数千次，这些边界由固定检查覆盖。清单同时记录随机分布与固定边界，避免把重复性和一般完成率混为一项。

行为不变的迁移先使用每个既有可达分层的 200 个冻结配对种子及原安全清单，逐项核对差异。改变行为的提交按第 5 节另行确定样本数；不再采用“200 对不能判断就扩到 400 对”的规则。双方使用同一布局和注入列表，首次正式运行前清单还须固定方向、速度带、入口偏移和材质替换。

正式跟随是本阶段的扩展探针，在 R28-1／4／3 通过后验证。它只使用已知地形和合法目标事实，具体范围见第 6.1 节。旧 `follow.py` 不走正式导航链，不能用来证明探针通过；没有正式跟随基线时如实声明，不能拿旧按键跟随器与新导航直接作同比。

## 4. 指标定义

| 指标 | 定义 |
|---|---|
| 任务成功率 | 可达正例在原总预算内完成的数量／全部冻结可达正例；首次失败和内部恢复分别记录 |
| 到达用时 | 从正式任务接纳到满足目标且完成要求的身体交接；分别报告运动 tick 和单进程单调墙钟 |
| 停顿 | 有移动需求时，连续至少 3 个运动 tick 的水平速度小于 0.1 格／秒；必要等待、正常终点停止和异常停顿分别计数 |
| 指令响应 | 从新指令进入正式 driver，到旧执行资格被撤销、首次向新目标移动、身体安全交接这三个时刻分别计时 |
| 首次移动 | 从目标确定且事实足够，到输入实际应用并观察到有效位移；规划、信息与资源不足分开说明。目标已经满足时标为无需移动，不算迟到 |
| 恢复代价 | 每任务恢复开始次数、规划请求次数、无进展时长、身体收尾时长；重复通知不计为新恢复 |
| 失败与取消 | 按预先类别报告发生率和结束用时，不混入成功到达用时，不从总任务数中删除 |

速度和位置来自正式身体观察，输入是否移动来自实际应用采样，不能只看提案。目标身份未变但修订频繁的任务，其总预算不得重新起算。进展按有效路线前移、动作完成或取得当前阻塞事实判断，不按距离终点变小、转头、重发请求或原地抽搐判断。

俯视脚本、瞬移或测试预观察对指标的影响要单列。持续追击的正式窗口与取消后的收尾窗口分开；不能用窗口后的记录解释窗口内停顿。

## 5. 冻结的比较门槛

### 5.1 先按实际改动分类

每个候选提交在运行前声明“行为不变迁移”或“改变行为”。合并恢复分支、复用旧结果或改变预算上限，都可能改变实际结果，不能仅按 R28 编号分类。对同一提交拆不开的两类改动，按改变行为验收。

行为不变迁移逐一比较任务终态、控制命令、停止／交接、恢复次数和关键事件顺序。随机编号与日志时间可以归一化；真实 tick、应用窗口、输入和责任不能抹掉。每个不同种子须有旧／新轨迹、第一处分歧、原因和检查。新增失败或未解释差异阻止该迁移关闭。若差异来自有意改变规则，另开行为修改提交，不能写一句“合理”后继续按等价迁移通过。

真实后台调度可能产生差异。先在确定性注入下验证迁移，再用正式异步链检查真实期限；不能因确定性模拟一致而省略在线路径，也不能把环境波动全部算作代码退步。

### 5.2 改变行为时的样本和成功率

“实质退步”在本阶段定义为：扰动组任务成功率降低超过 **1 个百分点**。设 `b` 为基线成功／候选失败数量，`c` 为基线失败／候选成功数量，`n` 为全部配对任务，差值 `Δ=(c-b)/n`。通过条件只有一条：**Δ 的配对 95% 区间下界不低于 -0.01**；不再另设一个可能与区间冲突的点估计拦截。区间上界也低于 -0.01 为退步，其余跨界结果为不确定，不计通过。

首版使用 [Tango 配对二项得分区间](https://pubmed.ncbi.nlm.nih.gov/9595618/)，保留双方都成功、仅基线成功、仅候选成功、双方都失败四格计数。R28-0 的工具检查须覆盖零不一致、稀少不一致和互换基线／候选，并与独立计算核对；不能用零方差 Wald 区间伪造确定结论。只增加统计纯函数，不升级现有依赖。

样本数在正式比较前确定。独立探索清单用于估计结果不同的比例，全部原记录保留，但不计入正式验收。以至少 **80%** 的判断概率作为规模校准目标：在真实差值为零、探索数据给出的保守不一致比例下，使用上述固定区间模拟门槛能否给出结论。正式种子每层至少 1,500 对；不足时预先增加到校准所需数。评审的近似式仅作预算估计：不一致比例 4%／8% 时，约需 3,200／6,400 对才能达到这一量级，实际规模由选定区间的校准决定。

校准报告固定随机种子、重复次数、区间实现版本和最终样本数；正式清单每个声明分层都要有足够样本，不能将多个薄弱分层合并后凑满。重复同一固定地图只验证重复性，不能冒充独立布局样本。正式结果出来后不追加种子直到通过；若样本或运行预算不足，记录证据不足，保留原发布版本。

正常输入的“至少 **99%**”明确指冻结集合的**点估计**，95% Wilson 区间另行报告，不宣称真实总体下界达到 99%。确定性正常对照仍全部完成；正常组也执行上述配对非退步检查，逐项分析新增失败。

### 5.3 用时、响应和性能

- 双方都成功的配对任务，平均与 P95 到达用时不得增加超过 **5%**。
- 异常停顿率和每任务恢复次数不得恶化超过 **5%**。基线为零时要求仍为零；初始探索中发现必须改变定义时，先更新决定和清单，不能在正式失败后解释成豁免。
- 可恢复地面条件下，事实足够后的首次移动、改变指令后的首次有效响应 P95 不超过 **5 个运动 tick**，相对基线不得增加超过 **1 tick**。空中与在途输入单列撤销资格和安全交接，不提前释放身体来赶响应。
- 正常控制准备 P95 继续要求 **≤8 ms**；输入实际期限、冷启动、预热和端到端耗时分别报告。

以上是固定集合的发布判断。耗时比较同时报告双方全部任务结果和失败／取消结束用时，避免让慢任务失败来改善统计。分位数取排序后第 `ceil(p × n)` 个样本，保留样本数，不平均各运行的 P95。配对成功率区间用于预先声明的随机分布；固定边界组不能据此推算一般环境安全概率。

### 5.4 Fabric 与结果解释

模拟承担配对比较和差异归因，Fabric 只做受影响的代表性对照和真实时序检查，不承担数千个样本的统计门槛。改变物理或局部控制时，仍按第 7 节扩到对应 M3 范围，不能用抽查覆盖不明影响。

以上是本阶段的初始发布门槛，不代表已测得结果。基线未达目标时保留差距，允许迁移工作继续，相关产品能力不签通过。若证据表明某阈值不适合该任务类别，必须在候选正式比较前写决定和新清单版本，保留旧结果；禁止候选失败后顺手放宽。

单个非安全体验反例不自动重开整个阶段。批次持续不达门槛时，对应步骤的产品验收不关闭。分类和最低功能门槛不能通过改标签绕过。

## 6. 复杂度与测试有效性

保存总源码、协调模块、会话、控制分支、枚举、活动字段、重复恢复入口和内部异常路径的基线。报告中包含新增与删除；日志词汇、协议枚举和业务类别分别标记，不能混为流程复杂度。

每步结束时，已迁移领域的重复入口必须减少；协调控制分支和活动状态不得净增加。若确有必要增加，提交证据与 D048 的例外记录，不靠移动到新文件或把判断塞进表达式达标。会话 2,000 行以内是目标；总协调代码和跨模块耦合同时检查。

R28-0 的测量工具可以增加代码，但进入生产迁移后必须由删除旧路径抵消。短期双接口只读适配列出删除步骤，权威状态不得双写。

逆向检查至少覆盖：去掉作用范围、错误清掉旧身体责任、无条件中性恢复、误接受过期证明、反证不可撤销、预算在修订时补回、缺诊断默认通过。错误副本须因行为检查失败，不能靠导入报错检测。

### 6.1 正式跟随扩展探针

首版不预测未知目标，不搜索未知区域，不使用未发布移动方式。跟随层只从合法目标事实产生 GoalState 和修订，调用正式导航；保持距离、暂时丢失目标和结束请求有类型结果。一次到达当前跟随区域不等于整项跟随任务结束，后续修订或 successor 仍沿共享身份、任务预算和身体交接规则。

R28-0 冻结任务时长、目标速度／轨迹、跟随区域、允许跟丢时间、停止要求和预算。正常可达任务须在窗口内满足冻结的追随与最终停止要求，点估计成功率至少 99%；首次移动和修订响应沿用第 5.3 节。新能力没有旧正式跟随基线时，报告首版门槛和限制；可以用同一目标流的已有正式移动目标链核对导航行为，不声称旧跟随器已取得同比改善。

固定清单必须包括：目标远离、横移、停下后再次移动；每 3／5／8 tick 修订；目标暂时丢失；修订与迟到、丢回执、丢仲裁、外力、取消的交叉组合。事件可重复，至少有一次目标持续移动导致旧终点不满足新目标，不能只测迎面靠近或瞬移转向。任务时间、目标真值与扰动用于测试判定，actor 仍只读正式观察。

扩展检查记录下列项目，提交前后同口径比较：

| 项目 | 通过条件 |
|---|---|
| 代码落点 | 新增薄的目标管理／driver／测试；Session 和监督者没有跟随专用判断分支 |
| 状态与预算 | 共同生命周期状态、恢复入口、权威账本净增加为 0；跟随自身业务状态单列，不伪装成会话状态 |
| 等待与责任 | 使用共享有界等待，退出后活动等待为 0；目标修订不重置任务期限，取消仍完成身体收尾 |
| 控制链 | Runtime → 正式导航 driver → Session → 接纳／执行链；无独立按键跟随器或测试补许可 |
| 检测有效性 | S1—S5、重复事件和相邻阶段检查通过；记录首轮审查的中断／交接及预算问题，并保留反例 |

任何跟随专用协调分支都需先修职责或明确本轮未完成，不能作为“临时适配”长期保留。首轮审查问题为零只是一项观察；本探针只检验目标持续修订类扩展，不能宣布未来所有能力都无需修改核心模块。

### 6.2 清单核销与时间盒

阶段第 6 节维护旧路径迁移清单。每个静态登记项须有删除、迁移或保留结论，以及正式路径检查；不允许仅报告总代码变少。原严格动作迟到、输入窗口与落地责任继续单列保留。

按阶段第 4 节的批次与日期时间盒登记结果，未通过批次同样计数。到期不会关闭安全门槛或最低功能要求。扩展探针、尚不确定的行为比较和未完成迁移均如实保留，现行 R27／M3 不被改写成 R28 结果。
