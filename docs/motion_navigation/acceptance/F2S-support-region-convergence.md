## 3. 几何和安全不变式

1. 目标、障碍、UNKNOWN 最坏占用和支撑形状边界进入同一张网格。
2. 返回矩形位于原 `GoalState` 内，而且内部每个网格单元都同时满足净空和支撑门槛。
3. 网格边界保证单元内部阻挡状态不变。单元内部代表点用于判断净空；四个顶点的支撑比例都不低于 `0.5`，该单元才可用。
4. 结果可以跨过旧算法人为切出的相邻块。不得跨越无效单元，不得使用外接矩形，也不得扩大原目标。
5. 所有合格单元都参与候选；结果按 `(-area, min_x, min_z, max_x, max_z)` 固定选择。
6. 固定随机世界的密集抽样不得发现矩形内部碰撞、未知、危险材质、流体、未支持形状或低于门槛的支撑。
7. 执行依赖只包含绑定矩形的净空、支撑、支撑面身份和真正定义其边界的 owner。
8. UNKNOWN 不能当 AIR。按最坏障碍裁剪后可以使用完全已知的安全子区域；执行区域本身未知时仍返回 `NEEDS_INFORMATION`。

## 4. 初选、调用链和复核不变式

- Session、规划尾段的真实终点和接纳使用 `standable_region_in_goal()` 完成首次选择。
- Session 先用代表点到目标中心的距离及 `SurfaceNodeId` 稳定排序，再顺序运行精确查询。遇到首个 `FEASIBLE` 后停止；没有可行区域时才汇总缺信息。
- 一次 Session 选面共用一个 `WorldQueryCache`。候选顺序和结果不受机器速度影响。
- `surface_overlaps_region()` 只能影响搜索候选，不能单独授权执行。
- 路线契约保存已绑定的完成矩形。复核只检查它仍在目标内、净空、支撑合格、材质允许，而且支撑面身份不变。
- 绑定矩形之外出现更优区域时，原路线继续有效。复核不得重新求全局最优，也不得要求选择器再次返回同一个矩形。
- Session 的状态字段、等待类型和动作分支数不增加。目标更新、取消、世界修订和输入失联继续走现有共同路径。
