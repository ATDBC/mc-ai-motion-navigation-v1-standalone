# F2-S：支撑区域收敛验收

日期：2026-10-08。状态：验收口径已冻结，尚未实施。

## 1. 基线与证据规则

- 实施基线为 F2-R 最终源码提交 `886ae1fc`；公开快照 `1ee76b6` 是同一实现的整理版。
- F2-R、v7、v8 和旧 Fabric 批次只读。新结果使用 F2-S 新目录和新清单。
- 任务开始前冻结场景 ID、种子、目标尺寸、方向、输入时序、预期分类和输入哈希。
- 有效可达任务未完成时仍计入失败分母。正确拒绝和能力边界单独报告。

## 3. 几何和安全不变式

1. 返回矩形位于原 `GoalState`、某个精确净空块和支撑合格区域的交集内。
2. 不使用外接矩形，不跨过两个分离的精确块。
3. 选定矩形的全部支撑网格顶点均不低于 `0.5`；固定随机世界的密集抽样不得发现内部低于门槛。
4. 所有精确块都参与候选；结果按 `(-area, min_x, min_z, max_x, max_z)` 固定选择。
5. 执行依赖只包含选定矩形的净空、支撑、支撑面身份和定义边界的障碍 owner。
6. 选定矩形的依赖变化必须重放同一查询；矩形、参考点、高度或支撑面身份不同则原路线失效。
7. UNKNOWN 不能当 AIR。按最坏障碍裁剪后可以使用完全已知的安全子区域；执行区域本身未知时仍返回 `NEEDS_INFORMATION`。

## 4. 调用链不变式

- Session 选面、规划尾段的真实终点和接纳都使用 `standable_region_in_goal()`。
- 同一不可变世界、目标、身体和 profile 得到同一支撑面、查询状态和矩形边界。参考点可以随明确的 `connection_from` 改变；输入相同时必须一致。
- `surface_overlaps_region()` 只能影响搜索候选，不能单独授权执行。
- Session 的状态字段、等待类型和动作分支数不增加。
- 目标更新、取消、世界修订和输入失联继续走现有共同路径。

## 8. Fabric

平台外角、一格桥头和柱顶各运行四方向正常／首条晚 1 tick，最低 `24` 个正例。

每个试次要求：

- 原 `GoalState` 完成；
- 晚1由客户端实际应用账本确认；
- 零掉落、伤害、危险接触、窗口外输入和终态潜行；
- 所有输入来源注销；
- actor 不读取夹具全知地形。

“必须潜行才能完成”的实机属于下一路线优化阶段，不计入 F2-S 通过数。
