# F2：非中心地面路线执行与终点接近验收

日期：2026-10-07。状态：冻结范围验收通过；历史失败和能力边界保留。

## 1. 判定原则

- 测试分组、路线点、目标区域和可达性标签在运行前冻结。
- 正例必须完成原任务；有界失败仍是失败。
- 不能扩大目标、减少身体宽度或降低未知、危险、支撑和严格动作门槛。
- 开阔路线必须保留快速路径和逐帧行为。
- 组件模拟、正式链闭环和 Fabric 分开报告。

## 2. 非中心中途路线

每族覆盖四个方向，并同时覆盖正常输入和冻结的一帧晚到模型。

| 场景族 | 预期 |
|---|---|
| 格内偏移直线 | 不回到格心，沿折线完成 |
| 斜线 | 连续取得进展，不产生直角折返 |
| 中心转非中心 | 平滑进入第二段，不在连接点停稳 |
| 沿墙切线 | 允许无害墙裁掉横向位移，继续前进 |
| 墙角转弯 | 保持走廊内进展，不左右振荡 |
| 非中心小高差 | 复用现有连续高度证明和闭环 |
| 声明的边缘段 | 使用潜行防坠后继续 |

负例包括：中途正面墙、危险墙、未知墙、流体、未支持形状、走廊越界、未声明边缘能力和能力区间之外潜行。

门槛：所有预先声明可达的正例完成；负例不穿越、不掉落、不受伤，并有界返回现有失败或重规划结果。

## 3. 终点用例

终点正例族包括：开阔非格心、正面贴墙、沿墙接近、墙角、走廊尽头、边缘悬出 0.1 和 0.2 格。每族覆盖四方向和正常／首条晚一 tick。

反例包括：目标没有合法支撑交集、危险或未知接触、低顶无法恢复目标姿态、支撑移除、目标修订、取消、输入失联和外力。

门槛：

- 完成帧满足原 `GoalState` 的位置、支撑、模式、姿态、速度和朝向；
- 冻结可达正例 100% 完成；
- 掉落、伤害、危险接触和终态潜行为零；
- 中途墙不能因为终点能力而被接受；
- 种子 187 不得由成功转失败。

F2-0 会写入玩家常站位置清单的确切任务、当前结果和物理可达标签，之后不能按运行结果改分组。

## 4. 运动质量

- 进入非中心路线时不先回格心；
- 沿墙和墙角不连续左右振荡；
- 中心路线切入非中心路线时不机械停稳；
- 潜行只出现在声明区间，并在离开区间后及时释放；
- 终点接近不在墙前反复前后移动；
- 连续 10 tick 净位移小于 0.1 格且仍发送非中性移动，记为停滞失败；
- 与同条件持续输入参照相比，完成用时不超过 1.3 倍。

## 5. 安全和回归

以下门槛为零容忍：

- 未知当作可通行或可接触；
- 危险、流体或未支持材质被当作停车墙；
- 未声明区间启用潜行边缘策略；
- 路线走廊外继续输入；
- 严格空中动作的证明或身体责任被绕过；
- 业务终态前释放仍需收尾的身体责任。

开阔路线、连续高度、严格下降、跨隙、跟随和世界变化的无关场景必须逐项保持原行为。

## 9. Fabric 入口、smoke 与失败

入口为 `scripts/f2_ground_route_runtime.py`，复用既有本地 Fabric 部署、profile 4 表面深度、RuntimeNavigationDriver、NavigationSession、Runtime 和原始证据写入。搜索继续生成原中心节点，actor 只读取正式观察和原目标。夹具在任务开始前准备；原始命令与真实观察分开记录，不给 actor 安装真值地图。

正式清单为 93 项：10 个非中心／终点正例族 × 四方向 × 正常／首条晚一 tick，共 80 项；固定负例 4 项，中断代表 5 项，持续输入参照 3 项，late-2 窗口外故障 1 项。各族 smoke 先通过，遇到脚本或 P1 问题先保存失败并补最小回归，再进入完整矩阵。

失败保留如下：

1. 初次 Java 构建没有激活 JDK 路径。随后复用已有 launch manifest，仍核对 136 个 jar、100 个 remap jar 和 3911 个资产，未换客户端源码。
2. 走廊观察保留了旧墙角事实；新墙角缺被覆盖的下层支撑；0.2 格边缘缺平台外下方空气。原始 V3 回放定位缺格后，只增加真实观察位置和先观察支撑再建覆盖的顺序，不把未知当空气。
3. 多点路线的首条晚到实际记为 `applied_outside_window`。原失败任务虽完成，仍拒绝该 smoke。补首次静止入口中性证明后，首条晚一 tick 实际回执为 `applied`，单 tick 租约不变；late-2 仍被账本识别为窗口外。
4. 原版移动活塞的碰撞盒越过当前支持的邻格表示范围，观察协议明确失败。保留该实机错误，不扩大协议边界。外力代表改用原版无 AI 村民与实体 Motion 的真实碰撞，不直接写玩家位置或速度。
5. 完整矩阵第二批的斜向反向晚1场景，首条回执正确，但中途请求 793 的输入期望 tick 796、实际 tick 797。Java 前一帧间隔为 78.7217 ms，下一帧追跑间隔仅 15.708 ms；控制准备为 2.306 ms，观察至发送为 9.8874 ms。业务虽在原目标内完成且安全事件为 0，该批仍按期限未命中失败。保留原回执与时序样本；同代码最小复现正常／晚1为 2/2，同代码斜向族 8/8 复跑通过，最终有效批次期限错失为 0，没有放宽窗口或租约。

无伤害外力最小回归实际横移 0.53014 格，记录到运动残差 deviation；速度超过普通模型后安全失败，零掉落、伤害、危险接触，站立并释放身体责任。该有界失败保持原记录。最终同定义外力横移 0.35909 格，tick 165／168 的残差为 deviation，169 起回到 matched；既有再进入判断允许继续，同一路线控制器按实际身体逐帧选键，44 tick 后在原目标内停稳，driver 于 tick 200 成功，再由原 release 接口注销来源。没有新恢复驱动器或路线重锚。两次外力均符合冻结的有界结果要求，不能据此声明任意外力都能恢复成功。

三类参照使用与 actor 相同的场景、起点和原 GoalState。参照持续按住前进，再按预先固定的制动点释放；继续观察到零速且仍满足原目标。计时统一从首条非中性输入实际生效 tick，至首次中性输入后达到正式 0.1 格／秒停稳门槛且满足原目标的观察 tick。首次进入区域、首次原目标满意、首次停稳、driver 正式终态分别保存。

最小组合的非中心中途、贴墙和边缘比分别为 `42/42=1.000`、`42/34=1.235`、`58/54=1.074`，均不超过 1.3。连续 10 tick 非中性净位移小于 0.1 格的停滞为 0。正式完整清单按相同口径重新采集，三个比值相同，详见下表。

## 10. 能力边界

- 完成区域只接受精确轴对齐矩形，绑定常高普通 Walk；F2-R 按 D075 从障碍裁剪的多个精确块中选择最大块。连续高度和严格动作继续走原证明。
- 任意中途折线在组件中直接验证；Fabric 记录现有 Session 实际交付的非中心首段、沿墙和末段区域，没有新增路线优化器。
- 原目标内存在普通安全点时优先使用。`SNEAK_EDGE_GUARD` 只有执行器组件证明，正式路线尚无区间生产者。两个平台边缘终点不强制潜行，也不作为潜行实机证据。下一产品阶段为路线优化器设计与交付，必须由它成为第一个正式生产者并补必须潜行的 Fabric；若该阶段被更换，先删除不可达状态机。
- 外力代表同时保留有界安全失败和本轮原目标完成。动态实体避障、空中多技能恢复和移动活塞观察表示未由本阶段授权。
- 原 Task 1—4 基线、旧产品失败、修复前实机失败和源码来源均保留，不回写旧结论。
