## 本轮完成范围

本轮建立了下面这条正式链路：

1. 局部求解器从状态锚点生成真实命令、投影输入和预测轨迹；
2. 求解结果绑定规划请求、目标、路线位置、候选修订和风险策略；
3. `RouteAdmitter` 在执行前复核任务身份、状态入口、执行窗口、世界依赖和资源假设；
4. 执行器只接受已经接纳的候选，并按真实客户端输入回执逐 tick 前进；
5. 跨隙后的第一个转向可以写入同一份验证轨迹，随后在同一控制帧交给 Walk；
6. 迟到、错误 tick、目标变化、世界依赖变化和过期候选不会取得输入权限。

完整命令搜索已经有容量固定的 `MotionSolverWorker` 入口。控制侧提交和取结果都不等待求解。队列按动作连接保留任务，不用全局单槽把不同必要连接互相覆盖。后台结果如果已经落后于当前观察，接纳器会从最新状态重放同一命令序列；重放仍满足入口、途中碰撞、落点和资源条件时才生成新的证明。重放不搜索替代命令。

`MotionRouteCoordinator` 已接通活动路线、后台结果和路线执行器。`JumpGap` 现在默认要求经过该链；缺少证明时明确等待，不再静默退回旧控制器。历史 B09 回归只有在脚本中显式声明旧控制路径，才能绕过这项要求。

后台求解时客户端 tick 会继续前进。首条命令现在携带最早和最晚合法生效 tick；客户端回执给出真实生效 tick 后，执行器据此重新锚定剩余命令。后续命令仍要求连续、精确的逐 tick 回执。该规则只吸收候选交付延迟，不放宽动作中途的输入断档。

这轮没有扩大 B10-B 的入口范围。支持域仍是完整普通方块、低速站立入口、同高一格跨隙和四个正方向。落地后转向只支持一个正方向的首 tick。

## 本轮发现并修正的问题

第一次跨隙转向运行 `20260923T053825375962Z-ffa6d2ea` 中，稳定落地 40／40 通过，但第一次转向预检失败。求解结果要求改变运动方向，实机脚本只发送了前进键。修正后，方向要求会在同一个控制帧转换成视角增量。

默认协调链增加后保留了三次失败产物。`20260923T082539535104Z-0b2497d0` 把前面基线的旧输入样本灌入新建的路线局部账本；现已只让局部账本接收本路线拥有的应用样本。`20260923T082909182490Z-23531801` 证明路线决策必须把证明命令编号和期望 tick 一起交给输入出口，不能由调用者猜测。`20260923T083302580358Z-a019b110` 证明后台求解期间客户端 tick 会前进，首条命令必须使用候选启动窗口和真实生效 tick 重新锚定。三次失败均保留，最终通过产物没有覆盖它们。

B07 首次回归 `20260923T055150474410Z-279de6fa` 暴露出一个旧检查过严的问题。它要求身体碰撞箱完整落在单个踏面内，导致玩家无法进入真实可站立的楼梯半格踏面。现在改为检查脚点属于声明踏面；通路和终点支撑继续由扫掠查询负责。修正后 16／16 通过。

B08 两次运行 `20260923T055858661725Z-bbeb661c` 和 `20260923T060249936975Z-c24f8dc2` 的运动检查都通过，但场景结束后整理大报告时，实时客户端仍持续产生未读取的输入采样，最终填满固定容量账本并崩溃。现在所有 B03–B10 单客户端运动验收都会先关闭实时会话，再离线整理报告。第三次运行完整通过，且没有残留进程或端口。

失败产物保留，不用后续成功覆盖。

## 组件和反例检查

组件测试覆盖：

- 目标 ID 或目标修订变化时，旧候选失效；
- 请求代次、路线修订、动作位置或候选修订变化时拒绝；
- 状态锚点已经前进、执行窗口过期或世界依赖变化时拒绝；
- 原始求解结果不能直接交给执行器；
- 输入在错误 tick 生效时不推进动作；
- 空中取消或输入失联后，执行器仍保留落地责任；
- 等待输入回执时不提交额外中性输入；
- Walk → Sprint、Step → Step 和 Sprint 制动 → JumpUp 的同帧交接契约；
- 狭窄到无法容纳身体的落地区域明确返回不支持。
- 后台进程能返回有界跨隙求解结果，且两个不同连接都能交付；
- 晚到结果必须在最新锚点重新验证，入口已经偏离时拒绝，不能沿用旧落点。

当前运动导航专项检查为 311 项通过。迟到结果重放在同一进程内的旧测量只用于确认当前实现没有明显控制帧负担，不替代 Fabric 端到端时序验收。

## 结论和边界

B10-C 和整个 B10 在冻结范围内通过。普通已知地形规划可以保留同一对支撑面之间的不同动作边，并用包含模式、姿态、方向和速度区间的 `PlannerStateKey` 避免错误合并。`JumpGap` 的默认执行链已经是后台求解、当前状态接纳和回执驱动执行。

本结论不包含带速起跳、Sprint 直接进入 JumpGap、主动 Crawl、攀爬、流体、特殊接触、未知探索或动态实体。矩阵以外的新组合仍须先声明入口、出口、时序和证据。
