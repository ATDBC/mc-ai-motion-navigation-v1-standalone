# F2-SP：目标选面性能修正验收

日期：2026-10-08。状态：已通过。F2-S 可以进入任务 4；任务 4、v9、旧大集合和 Fabric 尚未运行。

## 1. 验收范围

本轮只验证两项修改：

1. 同一次目标选面中的支撑面发现和精确区域查询共用 `WorldQueryCache`；
2. 目标列按几何下界惰性查询，只跳过已证明不可能改变选择的列。

不验收新的路线、动作、目标语义、后台工作或生命周期。

## 3. 正确性门槛

### 3.1 缓存

- 不传缓存时，`query_support_surfaces()` 的状态、表面、依赖和 missing 与修改前一致；
- 传入缓存时，结果逐项一致；
- 同一次目标选面的所有列和精确区域查询使用同一个缓存对象；
- 缓存与世界身份不一致时明确失败；
- 缓存不跨 observation frame 或独立目标选择保留。

### 3.2 选择结果

测试侧使用完整列扫描作为参照。普通方块、非完整表面、多个高度带、四方向、列乱序和等距离场景中，惰性查询必须选择相同 `SurfaceNodeId`。

等距离时继续使用 `SurfaceNodeId`。任何无法证明不会赢得平手的未查询列，都必须查询。

### 3.3 UNKNOWN 与 missing

- 仍可能产生更优候选的 UNKNOWN 列必须进入 missing，并阻止选择完成；
- 已由下界证明不可能改变当前最佳候选的 UNKNOWN 列不进入本次 missing；
- 没有可行候选时必须扫描全部列，并返回全部相关 missing；
- UNKNOWN 不得变成 AIR、BLOCKED 或默认安全事实；
- 新 revision、取消和晚到观察继续使用现有身份与生命周期。

## 4. 错误副本

至少证明下列错误能被检查发现：

- 支撑面查询没有使用传入缓存；
- 接受属于另一份世界的缓存；
- 只按距离下界早停，遗漏 `SurfaceNodeId` 平手；
- 忽略可能更优的 UNKNOWN；
- 无可行候选时没有完整扫描；
- 用墙钟或候选数上限停止；
- 为通过性能门槛降低目标修订频率。

选择结果、node 或 relevant missing 不确定时，性能结果无效。任一门槛失败即停止，不进入正式 D061。

## 9. 实际结果

### 9.1 正确性和边界

独立完整扫描参照覆盖 `96` 个固定随机目标，另有非完整表面、多高度、四方向、列乱序和等距节点场景。惰性查询与参照选择同一个 `SurfaceNodeId`。相关 UNKNOWN 继续返回 missing；已经由下界证明无法改变选择的 UNKNOWN 不再阻塞。没有可行面时仍查询全部列。

缓存检查证明：不传缓存和传缓存的结果相同；同一缓存的第二次同列查询没有新增世界事实读取；错误类型和另一份 `WorldView` 都明确失败。目标选择中的列发现和精确区域查询使用同一个缓存。

完整 motion_nav 检查曾运行 `1686` 项。功能相关出现一条 D064 旧断言，它要求等待已经被 D077 证明无关的 UNKNOWN；断言已改为验证不等待、不停步和修订继续生效。另有一项墙钟区域基准只在完整套件负载下失败，隔离正式运行通过；公开快照指纹因本地生产源码已变化而保持待同步。直接受影响的目标选择、支撑面、F2-S、D063、Session 和完成区域检查均通过。
