# B04 验收记录：已知图规划与后台隔离

日期：2026-09-19
结论：通过；B04 完成

## 判定口径

| 项目 | 判定 |
|---|---|
| 图语义 | 只从完整已知的普通地面、净空和可扫掠连接建图；未知不进入可执行图 |
| 最短路正确性 | 1,000 个有限随机图与独立 Dijkstra 比较，可达性一致，代价误差在规定范围内 |
| 结果分类 | 完整范围无路、已知范围暂时无路、超时、未支持和完成分别表达 |
| 后台隔离 | 规划在独立进程；提交和读取不等待搜索完成 |
| 路线接纳 | 核对请求、目标、世界、相关变化和当前身体接入；候选不能直接写输入 |
| 路线寿命 | `route_id` 不随身体位置变化；相关几何变化由走廊独立记录并阻止继续执行 |
| 可执行走廊 | 当前有限前段有独立依赖和停止边界；远处变化不能撤销无关当前动作 |
| 500 ms 阻塞 | 安全前段可支撑至少两秒时，控制继续执行且不新增无谓停车 |
| 实机 | 独立 Fabric 完整已知空地、墙、坑、悬浮结构达到各自预期结论 |

## 组件结果

- `tests/motion_nav` 全套 77 项通过；
- 1,000 个随机有限图中，A* 与独立 Dijkstra 的可达性和最短代价一致；
- 墙、坑、悬浮墙和薄障碍分别验证节点、边、支撑、净空和连续扫掠；
- 未知范围无路、完整范围确定无路、展开预算耗尽和未支持分别返回不同状态；
- 快照按调用方给定的格数分批复制。复制期间地图几何变化会返回 `STALE`，不能把多个几何版本拼成一份快照；最后一批转移已经校验的事实，不再整份重复制；
- 后台进程同时承担按需构图和 A*。提交与轮询不等待搜索；最新请求覆盖积压请求；结果槽遇到发送线程竞争时由后台重试；进程退出不合成路线；
- 500 ms 阻塞注入期间，已有固定路线连续执行 12 帧，没有新增中性输入；
- 未支持碰撞形状和未经校准的支撑材质返回 `UNSUPPORTED`，不会伪装成完整范围确定无路；
- 路线接纳会拒绝旧请求、旧目标、旧世界和相关依赖变化。经过验证的身体接入段会进入实际固定路线，连续同方向网格点在交给 B03 前合并，完整依赖仍保留；
- 正式运行的每帧导航观察会列出语义发生变化的格子，并及时交给当前走廊；重复观察同一事实不会造成误撤销；
- 接入段独有格发生变化会撤销尚未完成的接入；走完接入段后，这些依赖退出当前走廊。较短走廊在接纳时和首次 `update(0)` 时保持相同长度与停止节点；
- B04 发现并修正了 B03 的一个时间尺度混用：停止尾迹继续用于安全否决，动作评分改用输入租约结束时的短期状态。高墙和悬浮墙拐角闭环通过，B02／B03 既有测试没有退化。

## 证据边界

- 本阶段只证明完整已知、同一高度、已校准草方块上的步行规划；
- 首版按需搜索只使用四邻接和统一步行时间，不评价连续空间最短曲线；
- 还没有正式未知探索、动态实体局部绕行、对角边、增量修路或跨高度动作；
- Fabric 四场共享一块完成过合法勘测的测试区域。它们验证不同障碍语义，没有声称是四张独立地图；
- 坑安排在最后，避免同一格快速“挖掉再填回”时，较早发出的空气确认结果晚到并暂时覆盖刚观察到的支撑。这是测试夹具的异步时序边界，原始失败记录仍保留。
