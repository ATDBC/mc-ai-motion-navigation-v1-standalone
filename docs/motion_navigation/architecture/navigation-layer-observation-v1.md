# 导航层匿名几何观察原型

日期：2026-09-18
状态：B02 运行原型；尚未接入长期世界知识

## 解决的问题

该原型验证导航层能否低延迟获得视锥内的空气、碰撞和未知，并让人直接检查机器人拿到了什么信息。它不控制角色，也不执行寻路。

## 数据语义

每个当前格子具有两个独立维度：

| 字段 | 取值 | 含义 |
|---|---|---|
| 知识状态 | 当前／未知 | 本帧是否实际完成查询 |
| 导航类别 | 空气／无碰撞非空气／有碰撞 | 只服务通行判断 |

有碰撞格另外保存 `empty`、`full_cube` 或局部长方体列表。流体使用独立布尔值，不和碰撞或空气混成一个枚举。

当前原型不保存历史。离开本帧视锥后，网页只把该处显示成当前未知。B02 后续把当前快照接入世界会话和历史所有者时，再决定保留与失效规则。

## 采集范围

- 以玩家第一人称眼睛为相机。
- 水平和垂直视场均为 120°。
- 最大距离 16 格。
- 前方障碍不截断导航查询。
- 只读取已加载区块；未加载部分计入 `unknown_cells`。
- 单帧最多处理 25,000 格和 25,000 个连续段，超过立即失败，不能静默把尾部当空气。

## 实时链路

```text
Minecraft 客户端 tick
  → 匿名视锥采样和连续段压缩
  → 最新帧单槽交接
  → 本机持久 TCP
  → Python 最新快照中继
  → SSE
  → 浏览器第一人称 WebGL2 三维视图
```

Minecraft 主线程只生成快照并替换待发送帧，不等待网络。发送线程和服务端都只保留最新帧。网页变慢时会跳过旧帧，不会积压后再显示已经过时的位置。

网页使用与机器人相同的位置、偏航角和俯仰角投影匿名三维信息。已知空气显示为低亮度点云；碰撞体显示为半透明表面和可透视轮廓；未知和查询范围外不生成几何。颜色只表达导航类别，不显示具体方块名称。网页只在收到新快照时重建 GPU 顶点缓冲，视图由 WebGL2 渲染。

## 权限与状态归属

- Fabric 原型只读客户端世界，不写键盘、鼠标或角色状态。
- 玩家继续使用普通 Minecraft 第一人称输入。
- Java 采样器拥有本帧原始查询结果。
- Python 中继只拥有最新的已验证传输快照。
- 网页只负责显示，不把任何值反馈给游戏。
- 数据契约拒绝 `block_id`、注册名、物品 ID 等身份字段。
