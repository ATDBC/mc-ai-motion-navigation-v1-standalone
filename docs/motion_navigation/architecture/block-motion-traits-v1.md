# 方块运动特征 v1

日期：2026-09-19
适用阶段：B06 起

## 要解决的问题

方块注册名不能直接决定怎么移动。石头、泥土和木板可以共用普通地面参数；冰、蜂蜜块、蛛网、水和梯子即使几何相似，也会改变速度、接触结果或可用动作。

## 数据归属

`WorldKnowledge` 继续拥有“某个世界坐标是什么方块、何时观察到”的事实。`BlockMotionCatalog` 只回答“这种已知方块状态对运动有什么影响”。它不保存坐标，不读取隐藏世界，也不把未知位置补成空气。

固定注册表位于 `config/motion-navigation/vanilla-block-registry-1_21.json`。它由固定 Minecraft 1.21 客户端 JAR 的 `blockstates` 资产导出，并保存 JAR SHA-256。运动规则位于 `block-motion-traits-v1.json`。

## 分类顺序

对一个已知 `BlockGeometry`，依次判断：

1. 注册名是否在固定 1.21 清单中；
2. 是否属于已经验证的普通地面模型；
3. 实际碰撞是否仍是完整方块，且不是流体；
4. 是否带有已登记的特殊效果；
5. 其余情况返回未支持。

结果只有三类：

- `SUPPORTED`：当前能力可以直接使用；
- `DEFERRED`：已识别特殊机制，但对应阶段尚未实现；
- `UNSUPPORTED`：注册名未知、状态几何不符或行为没有登记。

未知状态不能默认使用普通参数。无碰撞也不能直接等同空气，因为流体、火、蛛网等方块仍有运动或危险效果。

B06 的 v2 运动 Profile 必须同时绑定方块目录和地面模型。Walk 与 JumpUp 每次检查扫掠、身体占用和支撑时，都会对查询依赖中的已知方块应用同一份分类。几何查询先回答碰撞、支撑和未知；能力层再拒绝特殊效果、未分类方块和普通注册名的异常形状。

## 当前普通地面模型

`ordinary-ground-v1` 当前包含：

- `minecraft:dirt`
- `minecraft:glass`
- `minecraft:grass_block`
- `minecraft:oak_planks`
- `minecraft:stone`

这五种方块必须同时满足完整碰撞、非流体和普通身体条件。Fabric 替换试验证明它们可以共用 B06 的步行和低速一格上升参数。该结论不外推到冰、半砖、楼梯或 mod 方块。

## 扩展规则

新增地形时，优先增加运动影响或几何能力，不为每个方块复制控制器。一个方块只有在规则和代表实测都支持时才能加入普通等价类。相同注册名的不同状态若改变几何或机制，必须分流；当前分类器至少会把普通注册名的非完整几何拒绝为未支持。
