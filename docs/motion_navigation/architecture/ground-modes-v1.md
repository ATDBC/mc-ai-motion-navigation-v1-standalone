# 地面移动模式 V1

日期：2026-09-19
适用阶段：B08

## 1. 要解决的问题

B07 已能在已知支撑面上步行，但执行器只接受站立步行。B08 要在不复制寻路、路线跟踪和安全扫掠逻辑的前提下，加入 Walk、Sprint、Crouch，以及已经合法进入后的 Crawl。

四种模式共享“沿哪条路线走”和“未来轨迹是否安全”的算法。它们的身体高度、输入、动力学、进入条件和可用资源不同。这些差异由地面模式配置声明，不能散落在规划器和执行器中。

## 2. 状态归属

| 状态 | 唯一来源 | 使用者 |
|---|---|---|
| 实际姿态、实际冲刺、实际潜行 | Fabric 正式观测，经 `BodyState` 投影 | 模式准入、执行确认、目标验收 |
| 饥饿值和饱和度 | Fabric 正式观测，经 `BodyState` 投影 | Sprint 准入和资源状态 |
| 模式动力学和输入要求 | `GroundModeProfile` | 固定路线控制器、局部安全预测 |
| 当前要求的地面模式 | 路线动作段的 `MovementTransition.mode` | 动作路线执行器 |
| 路线和几何依赖 | 规划结果及动作段 | 所有地面模式共用 |

输入中的 `sprint=True` 或 `sneak=True` 只表示请求。机器人必须从下一份正式观测确认实际状态，不能把已发送输入当作成功。

## 3. 模式定义

### Walk

- 预期姿态为 `standing`。
- 不请求冲刺或潜行。
- 实际冲刺或潜行尚未解除时，先释放相关输入并等待观测确认。

### Sprint

- 预期姿态为 `standing`。
- 对有前向分量的移动请求 `sprint=True`。
- 只有正式观测显示资源条件满足，才允许开始或继续。
- 控制器允许游戏用有限帧完成模式切换；超过上限仍未观测到实际冲刺，返回明确失败，不反复切换。

### Crouch

- 预期姿态为 `crouching`，并要求观测到实际潜行。
- 所有移动和制动输入都保持 `sneak=True`，直到取消已安全停稳或动作段结束。
- 潜行的边缘保护是额外保护，路线仍需通过普通几何和支撑检查。

### Crawl

- 只接受已经通过合法游戏动作进入的 `swimming` 姿态。
- Minecraft 1.21 实测中，低通道爬行时 `pose=swimming`，但 `isSwimming=false`。因此以姿态和“未浸没在水中”识别 Crawl，不把游泳标志误当作必要条件。
- B08 只负责保持该姿态下的移动，以及进入足够净空后退出。
- B08 不直接写姿态，不开合方块，也不宣称支持从站立进入一格高通道。
- 依赖水中入口的完整转换留到 B13。

## 4. 共享执行流程

1. 动作段给出路线、目标模式和经校准的模式配置。
2. 控制器先检查正式观测中的姿态、资源和地面状态。
3. 若模式正在合法切换，控制器发出受扫掠保护的输入，并在有限帧内等待观测确认。
4. 模式成立后，使用该模式自己的动力学预测候选轨迹。
5. 墙、坑、未知和输入失联继续使用固定路线控制器已有的硬安全检查。
6. 取消时使用当前模式的制动模型；安全停稳后才释放动作所有权。

相机朝向不属于移动模式。控制器继续把世界方向换算为当前相机坐标下的按键，因此转动相机不能改变路线方向。

## 5. 净空和低通道

身体碰撞箱来自实际姿态。扫掠查询必须使用当前观测碰撞箱，不能用站立高度替代 Crouch 或 Crawl，也不能因为目标模式更矮就提前缩小身体。

从低姿态退出时，先用目标姿态的身体高度检查原地及下一小段路线的净空。净空未知时返回信息不足；明确被挡时继续保持当前低姿态或报告阻塞，不能尝试站起后再依赖碰撞把身体挤回去。

支撑查询可能同时给出“已知支撑足够”和“更深一层形状拥有者未知”。此时未知格只能增加支撑，不能推翻已经成立的完整地面。执行器只在查询结论为“需要信息”时等待；不能因为结果附带了非必要的地下依赖而永久停住。

## 6. 资源和选路

本阶段只把 Sprint 的稳定准入条件接入资源契约。饥饿值来自正式观测；规划使用不可增加的保守资源值，执行时再次核验实际值。饱和度保留为观测事实，B08 不自行模拟完整饥饿消耗。

搜索必须保留同一站位上互不支配的“耗时、剩余资源”标签。较快的 Sprint 前缀如果使后续 Sprint 不可用，不能覆盖仍可完成目标的 Walk 前缀。

## 7. 不变量

- 所有模式仍只有动作仲裁后的唯一输入出口。
- 请求模式不等于实际模式；实际状态只来自后续观测。
- 未知净空不能当作空气。
- Sprint、Crouch 和 Crawl 使用各自校准的动力学，不由 Walk 最高速度乘常数生成。
- 模式切换有明确帧数上限，失败后返回原因，不无限重试。
- B08 不增加 Crawl 入口、跳跃、跨坑、下降、水中移动或探索能力。
