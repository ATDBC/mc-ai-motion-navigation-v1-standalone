# 动作规则接口 v1

日期：2026-10-07。实现范围：M1 的受控下降迁移候选；阶段因 Session 缩减不足而止损，不能据此开始 M2。

## 1. 要解决的问题

一种下降动作的风险、入口观察、安全停止、求解几何和完成条件原来散落在五个模块。现在由一个不可变的 `ActionSpec` 声明这些规则。原协调 owner 读取规则并继续负责运行中的状态。

## 2. 固定登记与显式声明

`actions/contracts.py` 定义所需事实，`actions/registry.py` 一次性登记现有五种动作。`actions/controlled_drop.py` 保存下降规则，`actions/existing.py` 保存其他动作的显式分类及当前确实复用的几何和控制器函数。

登记表没有运行时注册接口，也没有未知动作的兜底行为。缺少身体承诺、验证要求、风险函数、停止声明或实际需要的求解/控制器函数时，登记失败。`ActionRoute` 在构造时检查每段动作是否登记。

| 查询 | 描述什么 | 谁使用 |
|---|---|---|
| `body_commitment` | 是否需要保持一次高度/空中转换的身体责任 | 执行器交接 |
| `requires_verified_motion` | 是否允许绑定真实运动证明 | 执行器候选校验 |
| `expected_damage_points`、`tracks_damage`、`damage_committed` | 预计伤害、是否记账、何时不可逆 | Session 风险账本、执行器累计账本 |
| `stop_hold` | 当前帧保护、缺信息及依赖变化时的安全按键 | Session、执行器 |
| `entry_observation`、`precondition` | 入口几何与当前事实是否满足动作要求 | 入口检查、运动协调 |
| `needs_background_solving`、`solve_kind`、`solve_geometry` | 是否求解、求解类别、方向/落点/起点/最大 tick | 运动协调 |
| `controller_family`、`controller_factory`、`completed` | 使用现有哪类控制器、如何创建、观察到落地时是否已到达 | 执行器 |

所有字段都必须显式给出。其他动作的零风险和无采集需求也由各自声明给出。

## 3. 状态仍由原 owner 保存

`ActionSpec` 是冻结记录。查询函数不保存执行状态、等待时刻、恢复期限、作业世代、重试次数或身体拥有者。查询可以收到当前身份和观察快照，并返回绑定该快照的采集描述；返回描述不等于保存运行状态。

Session 继续判断 STOPPING、选择当前有效路线、保存 probe/grant、安排信息等待并提交控制帧。`action_preconditions.py` 的两个边界选择函数只读取快照，返回冻结的动作索引，不判断作业世代、不等待、不重试，也没有下降类型分支。

MotionRouteCoordinator 继续创建/接纳后台作业，处理 NEEDS_STATE、等待旧动作落地并从正式观察重锚。下降的入口需要采集是动作事实；何时暂停求解、给 Session 一帧检查机会仍是通用协调职责。

执行器继续拥有段索引、当前控制器、实际输入回执和累计伤害。监督者及既有交接模块继续拥有身体责任。停止声明只是安全按键查询，不授予动作决定业务终态或释放来源的权限。

## 4. 一个具体例子

六格直接下降声明自己的保守伤害、落点支撑与下部空气证据、入口区间，以及未离开支撑前要继续复查的条件。Session 把预计伤害交给现有任务账本，把缺少的落点证据交给现有采集 owner。若旧候选变成 NEEDS_STATE，原协调器继续负责落地和重锚，spec 不接管恢复。

## 5. 扩展和证据边界

测试专用的 `RegisteredDescentProbe` 只增加一种身份及不可变登记，复用现有下降几何与控制器。它能进入路线校验、风险、前提、求解描述、控制器创建、身体承诺及验证等待。接入时没有为它修改 Session、执行监督者或运动协调器。

这证明当前接口能接入一个使用既有下降行为的新身份，不代表新运动能力已实现。真正增加动作通常需要自己的实现、固定登记，以及静态 `RouteAction` 类型声明，仍须重新验收。

量尺保留动作记录和类型联合声明，另计运行时特判。规划边到 `ControlledDropSegment` 的唯一转换继续留在 RouteAdmitter。所有通用 `actions` 文件均参与量尺，只有具体下降实现按既定口径排除。

接口收回了动作规则，但 Session 只减少 52 行，未达到 100 行门槛。剩余入口、信息等待、身份及身体协调职责继续保留；本轮不为行数重新包装这些职责。
