# F1 已知世界正式跟随精简证据

本目录保存 F1-E 可以公开核对的最小证据。五个 `scenarios/*.json` 是对应已签署 Fabric 目录中的 `scenario-result.json` 原字节副本；`product-rollup.json` 保存原目录和原始文件哈希。逐帧轨迹、世界和日志仍保留在本地原目录，不复制进 Git。

`structure-audit.json` 如实保留原“十二个核心文件零修改”门槛失败。薄跟随层只调用导航的 `start`、`replace_goal` 和 `release`，没有保存规划、路线、接纳、恢复、交接、重试或输入账本状态；核心文件也没有跟随专用分支。D057—D068 暴露的通用修复仍真实修改了核心文件，因此后续只删不加的结构整理继续单独进行。

`test-summary.json` 记录完整运动导航 1,469/1,474。五项失败与 F1 验收第 12.5 节冻结记录一致，不把它们删出分母，也不写成完整通过。

这五场是代表性实机证据，不是统计成功率保证。
