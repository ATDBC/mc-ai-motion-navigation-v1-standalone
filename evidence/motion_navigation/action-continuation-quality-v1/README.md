# D053：限定共同出口与运动质量证据

本包保存同目标模拟对照、代表性 Fabric 四方向、微基准、中间失败和独立审查。它不是完整 R28 发布或全动作组合验收。

- `index.json`：范围、源码哈希、实际结果与计时。最终运动导航 935/935、质量及地面接续专项 21/21。
- `simulation/`：同一五场的旧整理版与当前实现完整结构化轨迹，gzip 仅压缩原字节。
- `quality-comparison.json`：从上述轨迹重新计算的结果。实际模拟任务 tick 保留原收尾口径。
- `fabric/`：最终批次 `51fa0655` 的原运行清单、结构化帧和原始正式观察／控制流。四方向 4/4，45—47 tick，无空中反向或松键。
- `benchmark.json`：代表 worker 任务与进程往返，不能代替完整帧期限。
- `intermediate/`：安全到达但仍松键的首次预检、较早的单方向通过，以及修正前组件失败。失败不会被最终通过覆盖。
- `review/`：独立只读检查与停止尾迹反例。`report.md` 是发现阶段记录，最终修正意见见 `release-review.md`。

新旧五场使用同一正式模拟链和同一目标。基线来源为 `11b8f50` 的整理版，不是按新版结果重新构造的旧代码。几何由模拟后端生成；它使用同一个计算器，不能检出计算器和原版物理的全部差异。

Fabric actor 只消费 profile 4 正式深度与视觉空气。实验搭建不写入 actor 的地图；本包不包含服务器世界或图像。原始观察中的 JVM 时钟、原观察序号、实际应用请求身份用于计时，不直接相减 Python 和 Java 时钟。

原恢复 R tick 的稳定资格保留。新的停止证据计算到真实水平零速度，总推演最多 2R，不延长动作窗口或输入权限。正常出口和失联后的实际部分支撑着地分别判断；后者仍必须查询当前世界净空与原最小支撑比例。

本轮没有修改拐角提前松键或墙接触，不声明全面混模式、疾跑跨隙、主动探索或完整长期运行通过。既有上升／下降共用接口已接线和组件检查，全部新组合的实机门槛仍打开。

压缩文件可直接用 Python 的 `gzip.open(..., 'rt', encoding='utf-8')` 读取。每个文件的原字节哈希见 `SHA256SUMS.txt`。
