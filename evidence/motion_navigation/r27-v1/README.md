# R27 公开验证记录

本目录补充 2026-10-01 的 R27 复审整改证据。它与 `representative-v1` 的历史归档分别保存，不替换旧记录。运行结果与边界见 [协调验收第 20 节](../../../docs/motion_navigation/acceptance/navigation-coordination-refactor.md#20-r27-复审整改结果)。

## 保存了什么

- `verification.json`：原固定、种子、中断、1000 序列、新 256 异步序列、8 个反向检查和控制准备耗时的结构化汇总。保留各原始汇总文件的 SHA256；任务成功、有界失败、取消与验证通过分别统计。
- 通过归档 `20261001T011413953243Z-1fc0308e`：20 个完整父层停止与正常对照、原 B11 60 个正例和 24 个反例，以及原 R27 四个专项。保留逐帧身体、应用采样、放置报告、释放依据与尾迹。
- 失败归档 `20261001T005545494033Z-c0fc3f0f`：前三类停止各 5 次和第一个正常对照的试次记录均通过，但其释放后尾迹发生 RPC 超时，整个批次为 failed。16 条通过的试次记录不能解释为完整批次通过；失败原因保留在归档的 `public-run.json`。

两个压缩归档合计 225,314 字节。仅保存结构化文件，不包含游戏世界、图像、进程日志、启动参数或本机路径。归档中原 JSONL 文件保持原字节，`public-run.json` 是从原运行结果选取的公开摘要，并列出各成员的哈希。

## 证据边界

FAILED 的错误方块观察和 CANCELLED 的库存交付缺口是明确的测试注入。身体惯性、在途输入和有限离地由额外标记的 Runtime 测试输入源作用于真实游戏，没有改写身体观察。原库存记录保留；被替换格子原始的完整世界观察未另行存档，不能把这一注入解释为自然反证。

最后两个信息接口拒绝检查晚于最终 Fabric 的源码冻结。归档保留当时的源码哈希；当前代码由组件检查覆盖，不能把本次公开提交当成整份 Fabric 源码冻结。计算器与游戏的模型一致性仍受现有能力范围限制。

## 怎样核对

`index.json` 列出归档哈希、体积、成员数和试次行数。`SHA256SUMS.txt` 覆盖本目录文件；仓库根的整理版校验也覆盖这些文件。

```text
python scripts/export_motion_navigation_standalone.py verify --root .
```

可直接用 Python 的 `tarfile.open(path, "r:gz")` 和 `extractfile()` 读取成员，无需解压。通过归档中的 `client-0/b11-summary.json` 应为正例 60/60、反例 24/24；`r27-parent-stop-trials.jsonl` 应为 20/20。核对停止安全性时还须读取同目录的 controls 文件和释放后尾迹，不能只看每行的 `passed`。
