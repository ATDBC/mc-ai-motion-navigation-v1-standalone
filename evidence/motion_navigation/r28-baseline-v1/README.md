# R28-0 正式导航链组件基线

本目录保存固定产品清单的基线，不代表 R28 生产迁移、持续跟随或 Fabric 已验收。

运行链为 Runtime → RuntimeNavigationDriver → NavigationSession → 正式规划／接纳／执行。游戏由既有 1.21 计算器模拟，worker 同步替代；测试时钟固定。场景覆盖指定点、连续高度、目标修订流和单列的严格下降，正常与 20% 一 tick 晚到分别计数。

全部任务保留在分母。`summary.json` 是汇总，`metadata.json` 绑定源码、清单、环境和工具哈希；`baseline.tar.gz` 保存逐任务指标、注入参数、完整压缩轨迹及迁移清单。SHA256SUMS 校验字节。归档没有画面、游戏日志或用户世界。

解包到新目录后，可以运行验收文档第 7 节的 `compare`。工具检查冻结分母、成对输入、原始轨迹哈希和摘要一致性，不接受缺证据的“等价”。

移动目标场景只提交正式目标修订，不包含实体观察或近战策略。持续跟随及速率预算是后续 R28-1／4 的范围。固定布局加入口扰动不等于独立随机地图，不能据此推算任意地图成功概率。模拟现实耗时只说明工具吞吐，不能当作 Fabric 控制或实际输入生效延迟。

共 1,600 场，1,438 个成功、162 个失败，冻结集合中安全违规、未处理异常及监视器证据缺口为 0。所有失败保留。各分层和未达到的门槛见验收第 8 节，不能把无安全违规写成成功率 100%。
