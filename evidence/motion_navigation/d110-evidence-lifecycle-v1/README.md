# D110 精简证据

本目录保存 D110 的 Windows 回归与唯一一次正式 B10 摘要。原始大文件保留在本地运行目录，Git 只保存可核对的统计、来源路径、字节数和 SHA-256。

- `windows-regression/`：直接与相邻检查、源树和公开快照正逆分片、Java 门禁及快照校验。
- `fabric-b10/`：600 秒 B10 命令、环境 preflight 和正式运行摘要。
- 正式运行完成全部功能与安全矩阵，关闭时间归因通过，ordered source 显式释放，trace 无丢弃。
- 唯一失败是 `b10b_solver_is_bounded`：142 个求解样本的最大墙钟为 39.2484 ms，超过 30 ms。该样本与唯一一次二代垃圾回收重叠，但现有 CPU 计时粒度不足以证明因果，因此 D110 不改门槛、不重跑 B10。
- Linux 专属 settle 与 fd 最终字节复核仍需 Linux 环境完成。
